# 本地开发与模型导出

## 本地开发

1. 执行 `npm install` 安装锁定依赖。
2. 执行 `npm run dev` 启动开发服务器，或双击 `runStart.cmd`。
3. 执行 `npm run build` 验证生产构建。

## Blender 导出

使用后台模式打开 `source/Specimen_Frame_Shared_Topology_Material_Slots.blend`，运行 `scripts/export_specimen.py`，并把唯一脚本参数设置为 `public/models/specimen-frame.glb`。使用 `--factory-startup` 避免用户安装的绘图插件干扰后台导出，使用 `--python-exit-code 1` 让校验失败反映在退出码中。

脚本只导出 `SPECIMEN_FRAME_MATERIAL_SLOTS`，校验两个材质槽的名称、顺序以及两个区域都有面。必须使用 `export_materials="EXPORT"` 保留材质分区；前端仅继承颜色并用现有 Transmission 材质替换导入材质。

本机已知 Blender 主程序位于 `F:/Blender/blender.exe`；启动器路径不是后台导出的脚本入口。路径属于本机信息，不应写入应用代码。

## 导出后检查

- GLB 包含一个目标网格和两个材质 primitive，名称与槽位映射正确。
- 浏览器加载适配后恰好有一个 Mesh、两个材质 groups 和两个独立材质实例。
- 分别操作两个面板，确认颜色、粗糙度等参数不联动。
- 生产构建和浏览器加载无错误。

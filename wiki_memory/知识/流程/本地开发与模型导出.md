# 本地开发与模型导出

## 本地开发

1. 执行 `npm install` 安装锁定依赖。
2. 执行 `npm run dev` 启动开发服务器，或双击 `runStart.cmd`。
3. 执行 `npm run build` 验证生产构建。
4. 执行 `npm test` 检查阵列算法与环境资源生命周期。

## HDRI 与阵列浏览器回归

- 使用 Blender 后台运行 `tests/generateEnvironmentFixtures.py`，在 `--` 后指定独立临时目录，生成 HDR、EXR、PNG、JPG 测试图；不打开或保存源模型。
- 启动 Vite，并用独立临时用户目录启动 Chrome 无头实例，调试端口默认为 9223。Windows 后台进程使用隐藏窗口。
- 运行 `node tests/browser-regression.mjs <测试图目录>`；可用 `CDP_URL` 和 `VIEWER_URL` 指定调试服务与查看器地址。脚本通过真实 DOM 文件输入和 lil-gui 控件验证功能，截图和报告写入该临时目录。
- 脚本会改变测试浏览器中的参数，不修改源资产或持久化设置。完成后关闭自行启动的测试浏览器，保留用户的开发服务器。

## Blender 导出

使用后台模式打开 `source/Specimen_Frame_Transparent.blend`，运行 `scripts/export_specimen.py`，并把唯一脚本参数设置为 `public/models/specimen-frame.glb`。使用 `--factory-startup` 避免用户安装的绘图插件干扰后台导出，使用 `--disable-autoexec` 禁止源文件自动运行脚本，使用 `--python-exit-code 1` 让校验失败反映在退出码中。

脚本只选择源对象 `SPECIMEN_OUTER_FRAME`，校验两个材质槽的名称、顺序以及两个区域都有面，仅在内存中规范对象名为 `SPECIMEN_FRAME_MATERIAL_SLOTS` 后导出，不保存 `.blend`。必须使用 `export_materials="EXPORT"` 保留材质分区；前端仅继承底色并用现有 Transmission 材质替换导入材质，自发光按网页默认强度 0 初始化。

本机已知 Blender 主程序位于 `F:/Blender/blender.exe`；启动器路径不是后台导出的脚本入口。路径属于本机信息，不应写入应用代码。

## 导出后检查

- GLB 包含一个目标网格和两个材质 primitive，名称与槽位映射正确。
- 浏览器加载适配后恰好有一个 Mesh、两个材质 groups 和两个独立材质实例。
- 分别操作两个面板，确认颜色、粗糙度等参数不联动。
- 生产构建和浏览器加载无错误。
- 当前资产应为 36 个三角形，外框/内框索引数 72/36，底色 `#f3faff` / `#d1aaff`；导出前后源文件哈希应相同。
- `npm test` 包含资产与实际 GLTFLoader 接入校验；`node tests/browser-emissive.mjs <独立输出目录>` 验证双槽发光、环境切换、100 份阵列、移动端及刷新默认值，可用 `VIEWER_URL` 指向开发或生产预览。

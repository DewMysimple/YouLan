# 本地开发与模型导出

## 本地开发

1. 执行 `npm install` 安装锁定依赖。
2. 执行 `npm run dev` 启动开发服务器，或双击 `runStart.cmd`。
3. 执行 `npm run build` 验证生产构建。

## Blender 导出

使用后台模式打开 `source/Specimen_Frame_Transparent_Default_Material.blend`，运行 `scripts/export_specimen.py`，并把唯一脚本参数设置为 `public/models/specimen-frame.glb`。

本机已知 Blender 主程序位于 `F:/Blender/blender.exe`；启动器路径不是后台导出的脚本入口。路径属于本机信息，不应写入应用代码。

## 导出后检查

- GLB 恰好包含两个目标网格且名称不变。
- `SPECIMEN_INNER_PANEL` 仍以 `SPECIMEN_OUTER_FRAME` 为父对象。
- 生产构建和浏览器加载无错误。

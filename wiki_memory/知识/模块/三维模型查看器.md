# 三维模型查看器

## 一句话结论

`src/viewer/createSpecimenViewer.js` 完整拥有 Three.js 场景生命周期，React 只负责挂载、错误显示和卸载。

## 关键契约

- 运行时模型：`public/models/specimen-frame.glb`。
- 源模型：`source/Specimen_Frame_Transparent.blend`，源对象 `SPECIMEN_OUTER_FRAME`；后台导出时规范运行时对象名，不保存源模型。
- 必需对象名：`SPECIMEN_FRAME_MATERIAL_SLOTS`。
- 材质槽依次为 `MAT_OuterFrame_TranslucentWhite`（外框）、`MAT_InnerPanel_TransparentLavender`（内框）。
- 启动从程序白色兜底独立加载用户指定的 `public/environments/citrus_orchard_road_puresky_4k.exr`；也可在浏览器选择本地 HDR、EXR、UltraHDR JPG、普通 JPG/PNG。清除图片恢复真正纯白。
- 外框和内框分别创建材质及 GUI 参数对象；同一网格的两个 groups 引用材质数组索引 0、1。
- 初始颜色来自 GLB 材质的 Base Color，并通过 Three.js 转为 GUI 的 sRGB 字符串；其他参数保留查看器默认值。
- 当前外框/内框底色为 `#f3faff` / `#d1aaff`。原生发光颜色及强度两槽独立，范围 0–10、步长 0.01，不随 HDRI 强度或阵列份数更改参数；默认值由深邃预设统一应用，局部光纹使用独立 UV1，不覆盖原 UV。
- 模型根节点旋转适配标准 Three.js 相机轴系。

## 常见修改位置

- 材质默认值与中文控件：`DEFAULT_MATERIAL_PARAMETERS`、`bindMaterialFolder()`。
- 自发光直接绑定 `MeshPhysicalMaterial` 继承的原生属性。局部光纹位于 `src/viewer/localEmission.js`；独立选择性光晕位于 `src/viewer/selectiveBloom.js`，采用官方 UnrealBloomPass / OutputPass，不把原画中的发光贡献重复相加。高强度发光可能使颜色分级变浅，不用额外染色抵消。
- 实际启动调校及物理对照按钮：`src/viewer/depthPresentation.js`；具体数值放代码和工作日志，不视为永久设计规范。“恢复默认效果”恢复两槽原色及指定内置图；两个对照按钮保留当前相机、阵列、底色及环境。
- 模型接入：`src/viewer/specimenModel.js` 的 `prepareSpecimenMesh()`。
- 初始朝向与自动取景：`frameModel()`。
- 资源释放：`disposeObjectResources()` 与查看器返回的清理函数。
- 环境与加载竞争：`src/viewer/environmentManager.js`；材质绑定显式 `envMap`，环境强度和旋转必须作用于每个材质，不能只改场景参数。
- 阵列评估和双分组几何：`src/viewer/arrayModifier.js`；始终以每层输入包围盒计算相对偏移，世界偏移转换回网格局部轴，保留根节点适配。
- HDRI/阵列面板和同帧更新：`src/viewer/viewerPanels.js`。不使用 lil-gui 持续 `listen()`，避免空闲动画循环。

## 常见陷阱

- 不要把相机 up 改为 Z 来迁就模型正面；应旋转模型根节点。
- GLTFLoader 会把两个 primitive 加载为 Group 下的两个 Mesh，不能直接假定目标对象是带材质数组的 Mesh；加载阶段通过 `mergeGeometries(..., true)` 恢复单网格双分组，并保留法线和局部变换。
- 按源材质名称匹配两个区域，避免依赖 GLTFLoader 的子节点顺序。
- 不要让两个插槽共享同一材质或同一参数对象。
- 修改控件后要调用 `requestRender()`，否则按需渲染不会刷新画面。
- HDRI 清除、选择和卸载必须使旧请求失效；失败保留当前环境。EXR 使用解码结果的方向标记；普通 JPG/PNG 为 sRGB，HDR/EXR/UltraHDR 为线性数据。
- 阵列重建必须保留两个材质 groups、原有法线与不可变基础几何，释放旧结果；不把外框与内框的材质参数合并。

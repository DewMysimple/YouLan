# ADR-007｜视频参考梦境环境与柔透呈现

## 用户指定方向

先分析 source 中粉彩与黑底两段时间切片视频；据此实现现有标本框的独立尽头亮源、随观察方向衰减的径向效果、慢速粉紫—奶黄混色背景，协调曝光与 Bloom；允许参考视频改善现有材质。

## 已确认边界

- 保留本地 Three.js Transmission、外框和内框独立控制、原模型与双材质区域。背景和亮心与标本主体分开管理。
- 背景可以实际动画，因此替代旧版“任何静止相机下都不连续渲染”的限制；暂停背景或切回静态背景后仍按需渲染。
- 保留 HDRI 选图、纯白兜底、纵深与颜色累积，并向视频的柔透纵深效果调校，不将视频推断视为原站源码事实。
- 具体材质值、屏幕近似、局部排序和验证结果见 [[日志/2026-09-03-分析双视频并实现尽头迎光与动态混色|本次工作日志]]，不将美术默认数值锁为永久规范。

原 [[决策/ADR-006-深邃默认呈现与局部光晕|ADR-006]] 中以静态 EXR 为启动可见背景、只处理局部光纹的部分由本次要求替代；原两槽、坐标与源文件保护继续有效。后续用户指定统一纵深入口、无限远亮心及速度范围，见 [[决策/ADR-008-统一纵深控制与无限远亮心|ADR-008]]，旧基础阵列面板不再使用。

参考视频前四秒的指针驱动相机视差由 [[决策/ADR-009-指针驱动三维相机视差|ADR-009]] 补充，不改写本决策的材质与背景边界。

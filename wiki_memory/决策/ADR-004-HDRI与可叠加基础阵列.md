# ADR-004｜HDRI 与可叠加基础阵列

## 用户确认

- 允许本地选择 HDR、EXR、UltraHDR JPG、普通 JPG/PNG 全景图片。原纯白启动默认值和旧内置图已由 [[决策/ADR-006-深邃默认呈现与局部光晕|ADR-006]] 的调好效果与指定 EXR 替代；清除和加载失败兜底仍为白色环境。
- 文件仅在浏览器读取，贴图和所有参数不持久化，刷新恢复默认。
- 基础阵列支持多层叠加，使用网页场景坐标 X 左右、Y 上下、Z 前后，不采用源 Blender 局部轴。
- 保留本地 Transmission 核心和双槽独立控制，整组阵列共享这两套材质；默认调校遵循后续 ADR-006。

## 环境管理

- 环境与模型独立加载；图片失败不阻止模型显示。替换成功前保留当前环境，清除或无可用图片时使用白色环境。
- 环境强度乘各槽原有环境贴图强度；不覆盖各槽参数。水平旋转同步更新显式材质环境和背景。
- 背景可单独隐藏、调亮度、调模糊；隐藏图片背景不移除环境照明。无图片的背景是 Color 白色，不受曝光或背景亮度影响。
- 资源管理按最新请求生效；清除和卸载使旧请求失效，释放旧纹理及临时 URL。

## 阵列规则

- 根据 Blender `source/blender/modifiers/intern/MOD_array.cc` 的输入包围盒和累积偏移行为独立实现 JavaScript 基础阵列；参考本地 Blender 修订 `3b82744fbfc`，不导入 C++ 引擎。
- “重置全部”恢复无修改器单件；新增层数量为 2，相对偏移 `(1,0,0)` 开启，恒定偏移关闭且为零。数量包含原件。启动由后续深邃预设生成纵深阵列，不改变基础修改器规则。
- 每层步距为输入包围盒尺寸乘相对偏移，加恒定偏移。后层复制前层完整结果。支持禁用、删除、排序及重置。
- 最多 8 层、每层数量 1–100、启用层合计最多 256 份；超限拒绝修改。允许负偏移，零步距提示副本重叠。
- 保留不可变的原始几何，世界坐标偏移转换回网格局部坐标；不改变模型根节点既有朝向适配。最终始终为单 Mesh、外框与内框两个 groups，不焊接、不重算法线。
- 同帧变更合并生成几何；“适配全部”保持观察方向并按阵列包围范围取景，普通参数变化不移动相机。

## 边界

不实现完整 Blender 修改器栈、长度拟合、对象偏移、旋转缩放、曲线、封盖、顶点焊接、导出或写回源模型。不增加多次折射渲染，前后重叠玻璃沿用既有 Transmission 的限制。

本决策扩展 [[决策/ADR-003-单网格双材质槽接入|ADR-003]] 的环境与展示能力；坐标适配继续遵循 [[决策/ADR-002-模型转为标准Three视角坐标|ADR-002]]。

后续用户要求结合 Three.js 资料与实践实现切片颜色分级，并反馈 HDRI 背景下层次不明显。对应扩展见 [[日志/2026-09-03-实现切片颜色累积与HDRI分级显色|切片累积工作日志]]；此追加不改变本次基础阵列规则，也不等同于完整多次折射。

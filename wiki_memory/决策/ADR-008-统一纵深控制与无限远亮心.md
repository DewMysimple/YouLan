# ADR-008｜统一纵深控制与无限远亮心

## 用户直接指定

- 亮心可以呈现无限远太阳，视觉大小与原来接近。
- 移除与深邃效果重复的阵列修改器，只保留纵深控制，数量 1–200。
- 梦境混色流动速度范围扩大到 0–2。
- 面板允许轻量整理，除已指定移除的阵列入口外，不删改其他参数。

## 当前约定

- “深邃效果”是唯一复制入口，数量包含首层；沿固定网页世界 −Z 排列。间距与首层取景参数保留，“适配全部”迁入此处，普通数量/间距调整不移动相机。
- 保持一个标本 Mesh、两个材质 groups、不可变单件基础几何及双槽独立控制；不修改 Blender 或 GLB。内部复用几何复制函数，不保留隐藏的修改器堆栈。
- 默认无限远亮心使用固定世界方向、有限代理坐标与远景深度；平移/拉近/纵深数量不改变角大小，转动或改变 FOV 则影响屏幕投影。不是固定在屏幕中心的图标，也不向矩阵写入 Infinity。
- 有限距离模式保留原来的“亮心距末层”和半径参数；无限远模式仅禁用距离输入、不删除或覆盖其值。亮心半径在无限远模式下控制角大小。
- 速度 0 暂停，0–2 使用相同时间系数；默认速度仍 0.18。保留后台暂停、减少动画偏好和静态按需绘制。
- HDR/EXR/UltraHDR JPG/JPG/PNG 本地选择、失败保留、竞争保护、纯白兜底、环境强度乘双槽强度以及资源清理沿用原环境约定。不上传和持久化。
- 延续 [[决策/ADR-007-视频参考梦境环境与柔透呈现|ADR-007]] 的材质/光效架构与边界，本次不重新调校材质默认值。

# ADR-010｜双场景隔离与共享背景

## 用户指定方向

将现有标本纵深定义为场景1，在同一开发服务器中增加与场景1隔离的场景2；场景2采用三层花粉粒子和中央能量核心，两场景共用相同的背景系统。

## 当前约定

- 场景1和场景2分别使用独立 `THREE.Scene`；不把粒子作为标本场景中的隐藏 Group。
- 两场景共用一个 `WebGLRenderer` / Canvas、PerspectiveCamera、OrbitControls、指针视差、HDRI 纹理与程序混色背景，因此开发地址和页面壳不变。
- 程序背景的时间、配色和相机矩阵共享；场景2使用独立背景网格与材质，不读取场景1的切片覆盖纹理或太阳遮挡状态。
- 场景1继续独占标本几何、透明排序、切片计数、局部 Bloom 和尽头太阳；场景2独占粒子几何、GPU 动画和中央能量核心。
- 任一时刻只更新和绘制活动场景，非活动场景停止动画；切换时分别保存并恢复相机与轨道目标。
- 场景2的远层微尘、中层花粉和近层花瓣各使用一个 `THREE.Points`，数量通过 draw range 调整，不按粒子创建独立 Mesh。
- 当背景和粒子都暂停时恢复按需渲染；粒子动画尊重 `prefers-reduced-motion`。

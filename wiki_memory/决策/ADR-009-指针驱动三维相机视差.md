# ADR-009｜指针驱动三维相机视差

## 用户指定方向

分析 `source/留下的记忆切成时间切片 蝴蝶飞过的时间，切成了76片每一片都是飞行中的一个瞬间。滚动逐帧穿过，向外拖拽，就能看到整段蝴蝶飞行动画被展开.mp4` 前四秒，并在开发页面增加鼠标驱动的轻微相机倾斜与视差晃动。

## 当前约定

- 不使用 CSS 或画布整体平移；在当前相机视平面上临时平移真实 Three.js 相机，并继续看向 `OrbitControls.target`，让近层、远层、尽头亮心和光束产生一致的三维视差。
- 指针位置映射到画布中心为零、边缘为最大幅度；默认幅度 2.4°，垂直响应略低于水平响应，保持参考视频中矩形基本竖直且没有明显滚转的观感。
- 使用帧率无关阻尼跟随，默认响应时间 0.35 秒；到达目标后停止额外绘制。鼠标离开画布时平滑回正。
- 视差只在一次渲染调用内施加，完成所有透明排序、太阳投影和后处理后立即恢复基础相机姿态，不改写用户通过 OrbitControls 建立的真实视角。
- OrbitControls 旋转、缩放或平移开始时立即让视差回正，交互结束后等待新的鼠标移动；面板区域不驱动视差。
- 尊重 `prefers-reduced-motion`；卸载时移除指针及控制器监听。

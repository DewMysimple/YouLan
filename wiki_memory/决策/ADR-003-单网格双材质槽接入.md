# ADR-003｜单网格双材质槽接入

## 背景

用户指定新 Blender 源文件为一个共享拓扑网格，要求保留外框、内框两个独立材质控制，并严格沿用现有本地 Transmission 框架和渲染逻辑。

## 决策

- 源资产为 `source/Specimen_Frame_Shared_Topology_Material_Slots.blend`，对象为 `SPECIMEN_FRAME_MATERIAL_SLOTS`。
- 槽位 0 为 `MAT_OuterFrame_TranslucentWhite`，槽位 1 为 `MAT_InnerPanel_TransparentLavender`；导出 GLB 时保留两个材质 primitive。
- GLTFLoader 从锁定依赖加载，模型适配阶段将两个 primitive 子网格按材质名排序并合并为单 Mesh 的两个 geometry groups，不重算法线或焊接顶点。
- 两个分组分别绑定独立 `MeshPhysicalMaterial` 和参数对象，面板使用“外框插槽管理”“内框插槽管理”。
- 材质初始值仅继承源 Base Color；颜色通过现有 Three.js 颜色管理转为 GUI 字符串。原有物理材质参数、控件范围、相机轴系、按需渲染与本地核心映射保持；后续 HDRI 控制和基础阵列按 [[决策/ADR-004-HDRI与可叠加基础阵列|ADR-004]] 扩展。
- 模型接入在本地 Vite 开发服务器验证；不涉及远程部署。

## 验证

检查 GLB 的单网格双 primitive、运行时单 Mesh 双 groups、两套控件独立性及生产构建。缺少对象或材质槽时显示现有中文错误提示并释放加载资源。

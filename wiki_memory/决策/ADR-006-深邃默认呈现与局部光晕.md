# ADR-006｜深邃默认呈现与局部光晕

## 用户确认的目标与范围

- 检查模型实体结构与内部侧壁；建立排除低 opacity、整片自发光及显色补偿的透射对照。
- 调整相机、间距和累积曲线，让中后段仍可区分颜色等级；增加局部发光、受控 Bloom 和协调背景。
- 最终呈现必须是已经调好、刷新后默认采用的效果，而不是要求用户自行配置。
- 内置 HDRI 替换为用户指定的 `citrus_orchard_road_puresky_4k.exr`，工程副本位于 `public/environments/`。
- 解决方案依据 Three.js 官方资料；保留本地 Transmission 框架、双槽独立材质、原底色与按需渲染，不写回源 Blender。
- 后续用户要求侧面也能看到内嵌紫色，不能只剩空心观感。对应修复及其非递归折射边界记录在 [[日志/2026-09-03-修复侧面内嵌紫色缺失|侧面内芯修复日志]]。

## 接口与边界

用户后续要求解决侧面额外饱和及顶部越界，保持内胆颜色与边界一致；修正见 [[日志/2026-09-03-统一内胆着色并修正顶部紫色越界|闭合投影修复日志]]，不扩展为完整内部多次折射。

- 保留原 `emissive` / `emissiveIntensity` 控制，通过原生 `emissiveMap` 限定局部光纹；两个槽位独立，阵列共享各槽材质。
- 光晕采用官方 `UnrealBloomPass` 与 `OutputPass`，局部发光和背景分开处理，避免天空高亮参与泛光；不添加全局光照。
- 提供“恢复调好的默认效果”“纯透射对照”“仅颜色层级对照”和首层取景；一般参数调整不自动重置相机。
- 颜色加深仍以实际视线重叠计数为依据。自定义软上限曲线是美术近似，不宣称为 Three.js 原生多次折射或物理逐层传输。
- 清除贴图仍回到纯白背景与白色环境；替换贴图仍最新请求生效、失败保留旧图。所有面板调整仅当前页面有效。
- 不把本轮具体美术数值视作永久设计规范；实际默认值、模型诊断和调校结果记录在关联日志及源代码。

## 官方依据

- [MeshPhysicalMaterial](https://threejs.org/docs/pages/MeshPhysicalMaterial.html)：物理透射、opacity 与 thickness 的意义。
- [MeshStandardMaterial](https://threejs.org/docs/pages/MeshStandardMaterial.html)：emissive、emissiveIntensity 与 emissiveMap。
- [选择性 Bloom 示例](https://threejs.org/examples/webgl_postprocessing_unreal_bloom_selective.html)、[UnrealBloomPass](https://threejs.org/docs/pages/UnrealBloomPass.html)、[后处理手册](https://threejs.org/manual/en/post-processing.html)：分离发光、线性合成与最终颜色输出。

# ADR-005｜透明模型替换与原生自发光

本决策的默认值与“不添加 Bloom”边界已由用户后续确认的 [[决策/ADR-006-深邃默认呈现与局部光晕|ADR-006]] 替代。以下保留为历史。

## 用户确认

用户确认执行新模型替换方案，选择采用新模型颜色，并只增加原生自发光，不增加 Bloom 光晕。

## 决策

- 源资产为 `source/Specimen_Frame_Transparent.blend`，源网格 `SPECIMEN_OUTER_FRAME`；仅在后台导出会话中规范对象名为 `SPECIMEN_FRAME_MATERIAL_SLOTS`，不保存源文件。
- GLB 保留单网格双 primitive，前端沿用原适配器合并为一个 Mesh、两个 groups；槽位 0 为 `MAT_OuterFrame_TranslucentWhite`，槽位 1 为 `MAT_InnerPanel_TransparentLavender`。
- 使用新源文件的底色，外框 `#f3faff`、内框 `#d1aaff`；其他物理参数保留网页原有默认值，不导入 Blender 的 Alpha、粗糙度、IOR 等参数。
- 两套独立 `MeshPhysicalMaterial` 和 lil-gui 参数对象继续控制所有副本对应区域。自发光颜色默认白色，强度默认 0，范围 0–10、步长 0.01，直接绑定原生 `emissive` 与 `emissiveIntensity`。
- 自发光不乘环境强度或阵列份数；保持现有曝光、色调映射、切片累积公式、按需渲染和刷新恢复默认行为。
- 不增加 Bloom、全局光照、逐层发光传输或完整多次折射。强发光会降低颜色分级对比，不以自定义着色补偿。
- 不改本地 Three.js 核心、不写回 Blender；已有用户删除不混入本次提交。

## 依据与关联

[MeshPhysicalMaterial](https://threejs.org/docs/pages/MeshPhysicalMaterial.html) 继承 [MeshStandardMaterial](https://threejs.org/docs/pages/MeshStandardMaterial.html#emissive) 的原生自发光属性。HDRI 和阵列继续按 [[决策/ADR-004-HDRI与可叠加基础阵列|ADR-004]]；视角继续按 [[决策/ADR-002-模型转为标准Three视角坐标|ADR-002]]。

## 验收

验证源文件哈希不变、GLB 36 个三角形及 72/36 索引分组、新底色、双槽发光独立、强度归零恢复、环境切换、阵列和刷新行为；执行生产构建与浏览器回归。

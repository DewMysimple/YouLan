# 系统架构

## 架构概览

这是一个无后端的 Vite 单页应用。React 只负责挂载和卸载查看器；Three.js 负责 GLB/HDR 加载、物理透射材质、相机、OrbitControls 和 WebGL 渲染；lil-gui 直接修改两套独立材质与全局渲染参数。

## 模块关系

| 模块 | 职责 | 依赖 | 入口 |
| --- | --- | --- | --- |
| React 壳层 | 挂载查看器并显示中文加载错误 | React | `src/App.jsx` |
| 三维查看器 | 场景、相机、材质、控制器、GUI、生命周期 | Three.js 本地核心与 addons | `src/viewer/createSpecimenViewer.js` |
| 环境管理 | 白色环境、图片解码替换、强度与资源释放 | 本地 UltraHDR 与 addons HDR/EXR | `src/viewer/environmentManager.js` |
| 基础阵列 | 逐层评估、偏移转换、单网格双分组生成及取景 | Three.js | `src/viewer/arrayModifier.js` |
| 扩展面板 | HDRI 与修改器控件、状态反馈、同帧几何更新 | 原生 lil-gui | `src/viewer/viewerPanels.js` |
| 深邃呈现 | 默认调校、纵深预设、首层取景与物理对照 | 原生 lil-gui、Three.js | `src/viewer/depthPresentation.js` |
| 局部发光 | 独立 UV1 和原生 emissiveMap 光纹 | CanvasTexture | `src/viewer/localEmission.js` |
| 选择性光晕 | 线性原画、局部发光代理、Bloom 与最终输出 | UnrealBloomPass、OutputPass | `src/viewer/selectiveBloom.js` |
| 模型资产 | 保存一个具名网格及外框、内框两个材质区域 | GLB | `public/models/specimen-frame.glb` |
| 模型接入 | 合并加载器产生的两个材质原语为单网格双分组 | Three.js BufferGeometryUtils | `src/viewer/specimenModel.js` |
| Blender 导出 | 选择指定对象并生成 GLB | Blender Python API | `scripts/export_specimen.py` |
| 构建配置 | 将 bare `three` 精确映射到本地 r186dev 核心 | Vite | `vite.config.js` |

## 数据流

源文件 `source/Specimen_Frame_Transparent.blend` 的对象 `SPECIMEN_OUTER_FRAME` 仅在后台导出内存中规范为运行时名称 `SPECIMEN_FRAME_MATERIAL_SLOTS`，不保存源文件。本轮内部侧壁诊断与导出修正见关联工作日志。自发光使用原生 `emissive` / `emissiveIntensity` / `emissiveMap`；后处理只扩散独立提取的局部发光，再统一色调映射。

Blender 源文件经导出脚本生成单网格、双 primitive 的 GLB；浏览器独立加载模型，将两个原语按材质名称合并为单 Mesh、两个 groups，分别绑定独立 `MeshPhysicalMaterial`，仅颜色读取源材质。环境在白色兜底上独立加载指定内置 EXR，模型就绪后应用调好的默认阵列、相机和局部发光。阵列从不可变基础几何生成，保留两个材质分组及 UV1。GUI 变更和相机操作触发按需重绘，同帧阵列修改只生成一次几何。

## 运行与部署

本地开发使用 `npm run dev`，生产检查使用 `npm run build`。产物是静态站点，不包含后端接口。

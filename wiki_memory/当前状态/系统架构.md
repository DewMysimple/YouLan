# 系统架构

## 架构概览

这是一个无后端的 Vite 单页应用。React 只负责挂载和卸载查看器；Three.js 负责 GLB/HDR 加载、物理透射材质、相机、OrbitControls 和 WebGL 渲染；lil-gui 直接修改两套独立材质与全局渲染参数。

## 模块关系

| 模块 | 职责 | 依赖 | 入口 |
| --- | --- | --- | --- |
| React 壳层 | 挂载查看器并显示中文加载错误 | React | `src/App.jsx` |
| 三维查看器 | 场景、相机、材质、控制器、GUI、生命周期 | Three.js 本地核心与 addons | `src/viewer/createSpecimenViewer.js` |
| 模型资产 | 保存两个具名网格及父子组合关系 | GLB | `public/models/specimen-frame.glb` |
| Blender 导出 | 选择指定对象并生成 GLB | Blender Python API | `scripts/export_specimen.py` |
| 构建配置 | 将 bare `three` 精确映射到本地 r186dev 核心 | Vite | `vite.config.js` |

## 数据流

Blender 源文件经导出脚本生成 GLB；浏览器并行加载 GLB 与 UltraHDR，按对象名绑定两份 `MeshPhysicalMaterial`，GUI 变更和相机操作触发按需重绘。

## 运行与部署

本地开发使用 `npm run dev`，生产检查使用 `npm run build`。产物是静态站点，不包含后端接口。

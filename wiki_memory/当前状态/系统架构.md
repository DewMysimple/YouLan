# 系统架构

## 架构概览

这是一个无后端的 Vite 单页应用。React 只负责挂载和卸载查看器；Three.js 负责 GLB/HDR 加载、物理透射材质、相机、OrbitControls 和 WebGL 渲染；lil-gui 直接修改两套独立材质与全局渲染参数。

## 模块关系

| 模块 | 职责 | 依赖 | 入口 |
| --- | --- | --- | --- |
| React 壳层 | 挂载查看器并显示中文加载错误 | React | `src/App.jsx` |
| 三维查看器 | 场景、相机、材质、控制器、GUI、生命周期 | Three.js 本地核心与 addons | `src/viewer/createSpecimenViewer.js` |
| 环境管理 | 白色环境、图片解码替换、强度与资源释放 | 本地 UltraHDR 与 addons HDR/EXR | `src/viewer/environmentManager.js` |
| 纵深几何 | 1–200 层唯一状态、同帧生成及远裁剪保护 | 复用 arrayModifier 基础双分组生成 | `src/viewer/depthStack.js` |
| 扩展面板 | HDRI/累积控件与状态反馈、用途分组及说明折叠 | 原生 lil-gui | `src/viewer/viewerPanels.js`、`panelOrganization.js` |
| 深邃呈现 | 默认调校、纵深预设、首层取景与物理对照 | 原生 lil-gui、Three.js | `src/viewer/depthPresentation.js` |
| 局部发光 | 独立 UV1 和原生 emissiveMap 光纹 | CanvasTexture | `src/viewer/localEmission.js` |
| 选择性光晕 | 线性原画、局部发光代理、Bloom 与最终输出 | UnrealBloomPass、OutputPass | `src/viewer/selectiveBloom.js` |
| 梦境环境 | 无限远/有限距离亮心、程序混色背景、迎光与遮挡近似 | ShaderMaterial、现有覆盖纹理 | `src/viewer/dreamAtmosphere.js` |
| 指针视差 | 指针映射、相机临时视平面偏移、缓动与轨道控制让路 | Three.js Camera、OrbitControls | `src/viewer/pointerParallax.js` |

## 数据流

源文件 `source/Specimen_Frame_Transparent.blend` 的对象 `SPECIMEN_OUTER_FRAME` 仅在后台导出内存中规范为运行时名称 `SPECIMEN_FRAME_MATERIAL_SLOTS`，不保存源文件。此前内部侧壁诊断与导出修正见关联工作日志。自发光使用原生 `emissive` / `emissiveIntensity` / `emissiveMap`；后处理扩散独立提取的局部发光与尽头亮心，径向效果在线性阶段合成，再统一色调映射。

Blender 源文件经导出脚本生成单网格、双 primitive 的 GLB；浏览器独立加载模型，将两个原语按材质名称合并为单 Mesh、两个 groups，分别绑定独立 `MeshPhysicalMaterial`，仅颜色读取源材质。环境照明在白色兜底上独立加载指定内置 EXR，可见背景默认使用程序混色；模型就绪后应用调好的默认纵深、相机和局部发光。纵深从不可变基础几何生成，保留两个材质分组及 UV1。静态时 GUI 变更和相机操作触发按需重绘，背景流动启用且页面可见时持续绘制，同帧纵深修改只生成一次几何。

## 运行与部署

用户最新四项视频参考目标与材质调校取代静态可见天空默认，见 [[决策/ADR-007-视频参考梦境环境与柔透呈现|ADR-007]]。独立背景进入透射渲染，环境照明仍独立加载；日轮发光与径向效果在线性阶段合成并统一输出。材质低覆盖与排序属于美术近似，物理对照保持可用。动态背景仅在可见且开启时持续绘制，关闭/暂停后仍按需刷新。

太阳投影在 CPU 侧计算圆盘屏幕半径和到最近视口边缘的有符号距离；`smootherstep` 生成空间软门限，帧率无关阻尼生成时间响应，统一驱动动态背景迎光、线性径向光与太阳 Bloom。过渡结束后渲染循环回到按需状态；光束扩散只改变屏幕衰减距离，不参与显隐。

指针视差在每帧透明排序与梦境环境更新前临时移动相机，并在全部绘制结束后恢复基础位置和四元数；因此所有三维层和屏幕光效共享同一视角，而 OrbitControls 的持久状态保持不变。视差缓动或梦境背景任一仍活动时继续请求下一帧，两者都静止后停止。

本地开发使用 `npm run dev`，生产检查使用 `npm run build`。产物是静态站点，不包含后端接口。

# 项目概览

## 项目名称

幽兰标本框 Transmission 材质查看器。

## 项目目标

用 React、Vite、Three.js 和 WebGL 在全屏页面中显示 Blender 导出的单网格双材质槽标本框，并为外框和内框提供相互独立的中文原生 lil-gui 透射材质参数。

## 当前阶段

本地单页查看器已可运行；主体单网格双插槽、可替换 HDRI、1–200 层统一纵深、中文面板、标准 OrbitControls 和按需渲染已实现。源模型为 `source/Specimen_Frame_Transparent.blend`，保留两槽原底色。用户最新要求分析粉彩与黑底两段视频，实现独立尽头亮心、迎光径向效果、缓慢混色背景，并按视频改善材质。当前以视频参考梦境呈现启动，保留 Citrus Orchard EXR 照明及物理对照；动画开启时按可见性绘制，暂停后按需渲染。呈现架构见 [[决策/ADR-007-视频参考梦境环境与柔透呈现|ADR-007]]；用户后续要求移除阵列修改器、保留唯一纵深入口、无限远亮心及流动速度 0–2，见 [[决策/ADR-008-统一纵深控制与无限远亮心|ADR-008]]。

用户追加要求同一种紫色随视线穿过的切片数逐级加深，并关注 HDRI 下的层次可见性。本轮实现、可调参数与验证记录见 [[日志/2026-09-03-实现切片颜色累积与HDRI分级显色|切片累积工作日志]]；不将美术默认值视为已确认的长期设计规范。

用户追加要求解决侧面看不到内嵌紫色的问题；实现与验证见 [[日志/2026-09-03-修复侧面内嵌紫色缺失|侧面内芯修复日志]]，沿用双槽原色及现有默认呈现。

无限远太阳的光束不再按镜头夹角提前衰减；太阳跨越相机视口边缘时使用可调的空间软带和时间响应平滑淡入淡出，正常画内保持完整显示。见 [[日志/2026-09-04-为太阳光束增加边缘与时间渐隐|太阳渐隐日志]]。

用户指定参考视频前四秒的鼠标晃动已实现为三维相机视差：近远切片产生不同位移，空闲时不覆盖 OrbitControls 姿态，回正后恢复按需绘制。旋转、平移和缩放开始时改为无跳变提交当前可见姿态，操作期间冻结视差，松手位置默认成为临时中性点，避免先回正和操作后再拉向一角。见 [[决策/ADR-009-指针驱动三维相机视差|ADR-009]]。

后续用户指出正侧面紫色不一致、顶部紫条未在内胆闭合，要求修复显示；实现与验收见 [[日志/2026-09-03-统一内胆着色并修正顶部紫色越界|内胆闭合与着色修复日志]]。

页面现在将上述标本呈现定义为场景1，并新增隔离的场景2“花粉星云”：远层微尘、中层花粉、近层花瓣与中央能量核心。两个 `THREE.Scene` 共用同一服务器、Canvas、HDRI 与程序混色背景，但场景专属几何、动画和后处理互相隔离；见 [[决策/ADR-010-双场景隔离与共享背景|ADR-010]]。

页面进一步新增隔离场景3“金菊闪柳烟花”：参考实拍拆为升空、爆心、金菊放射、冷绿白闪烁、闪柳下坠和余烬阶段。场景3使用固定 GPU 批次、独立时间线、独立可调夜空和独立 Bloom；桌面端实现与边界见 [[决策/ADR-011-隔离烟花场景与GPU批量轨迹|ADR-011]]。

用户随后要求结合指尖烟花网站与彩色花火视频深度改造场景3，并明确保留 Three.js 旋转。新默认彩色花火及原版对照模式的实现、交互和验证见 [[日志/2026-09-05-深度改造场景3为可旋转指尖彩色花火]]。

用户随后提出删除 HDRI，但附加条件为“若影响模型质感和显示则不删除”。同机运行时 A/B 已确认 HDRI 仍参与两槽物理材质的环境反射与高光，因此最终保留现有 HDRI 面板、加载链和资源；见 [[日志/2026-09-04-评估HDRI移除并决定保留|HDRI 移除评估]]。

场景4“无限花开”的最新要求是持续长出并展开新花瓣，最老外瓣逐片脱落后向右下方飘散；用户要求深入参考本机 `3d-blooming-flower`，替代整花冠叠加缩小的旧机制。沿用杜鹃花真实资产、独立 Scene、WebGL 与 HDRI，见 [[决策/ADR-013-无限花开按花瓣年龄展开与脱落|ADR-013]]；本轮具体实现见 [[日志/2026-09-05-按参考工程重构逐瓣绽放与脱落飘散]]。

用户追加要求参考 Paper Planes 与视频，在同一服务器添加大量纸飞机环绕星球的场景5，使用 `source/papierfliegerswap.blend` 和 `source/C1123低多边形地球气球C4D模型LowPoly Earth Pack/` 资产；具体实现和验证见 [[日志/2026-09-05-新增纸飞机环游星球场景]]。

用户进一步指定场景5展示星球之前先显示一架纸飞机，由相机跟随其飞行入场，再进入正式星球场景；实现与验证见 [[日志/2026-09-05-增加纸飞机跟随入场镜头]]。

用户随后指出入场背景与飞机相对相机运动太平淡，指定参考场景1纵深效果，在场景5增加云、少量太阳效果与更丰富的跟飞动势；实现与验证见 [[日志/2026-09-05-丰富纸飞机云层阳光与跟飞动势]]。

用户指定进一步建模一只蝴蝶，并在下一个场景展示翅膀扇动动画；对应场景6实现与验证见 [[日志/2026-09-05-建模蝴蝶并新增扇翅动画场景]]。

用户最新指定场景6按参考图改为奶白玫瑰红蝴蝶，缩细身体、丰富纹理、修正穿模并增加上翻幅度；进一步明确前后翅不得横向镂空，应连续衔接。实现与验证见 [[日志/2026-09-05-按参考重做玫瑰蝶并修复翅膀衔接]]。

用户进一步要求场景6补实身体附近的翅根连接、增加前翅上缘饱满度，并让左右翅膀的斑纹细节避免完全镜像。实现与验证见 [[日志/2026-09-05-补实蝶翼连接并丰富非镜像细节]]。
用户指定结合 Microsoft AI 原网站和本地演示视频，在场景7复现指针移动驱动的斑驳光影，并提醒该效果可能不是三维景物；参考分析、二维实现与验证见 [[日志/2026-09-05-新增微软参考二维斑驳光影场景7]]。

用户指定场景6采用与场景1一致的背景模式及迎光光束，蝴蝶水平放置、头朝光源。实现和验证见 [[日志/2026-09-05-蝶翼共享梦境背景并水平迎光]]。

## 核心目录

用户指定将本机 `codrops-depth-gallery` 添加到下一个场景并调整适配参数；对应场景8“纵深花廊”的接入、调校和验证见 [[日志/2026-09-05-接入Codrops纵深花廊场景8]]。

| 路径 | 用途 |
| --- | --- |
| `src/` | React 入口、页面样式与 Three.js 场景实现 |
| `public/models/` | 浏览器运行时加载的 GLB |
| `public/environments/` | 用户指定的内置 EXR 环境 |
| `scripts/` | Blender 后台导出脚本 |
| `source/` | Blender 原件与本地 transmission 示例源码 |
| `wiki_memory/` | 当前状态、决策、知识和工作日志 |

## 重要入口

- 页面入口：`src/App.jsx`
- 场景入口：`src/viewer/createSpecimenViewer.js`
- 模型导出：`scripts/export_specimen.py`
- 开发启动：`npm run dev` 或 `runStart.cmd`

# 当前约束

## 技术约束

- 页面技术栈为 React + Vite + Three.js + WebGL。
- Three.js 核心使用 `source/threejs-transmission/build/three.module.js`；运行时不依赖 CDN。
- GLB 必须保留 `SPECIMEN_FRAME_MATERIAL_SLOTS` 对象名，以及外框槽位 0、内框槽位 1。
- 运行时为一个 Mesh 和两个材质分组；两个槽位分别拥有独立 `MeshPhysicalMaterial` 和参数对象，不得共享材质状态。
- 材质与控制继续基于本地 `source/threejs-transmission`；源材质仅提供初始颜色，不导入其 Alpha、粗糙度、IOR 或透射参数。用户后续要求研究并实现切片颜色随重叠逐级加深，允许为此扩展显示逻辑，但不擅自改两槽原色或替换框架。

## 交互与界面约束

- 页面只显示全屏模型、原生 lil-gui 中文参数面板和加载失败提示，不添加额外装饰界面。
- 材质分组名称为“外框插槽管理”和“内框插槽管理”。
- 使用 `source/Specimen_Frame_Transparent.blend` 的几何与底色：外框 `#f3faff`、内框 `#d1aaff`。不自动导入源文件其他物理材质参数。
- 两槽独立提供原生自发光颜色和强度（0–10、步长 0.01），不乘环境强度或层数。用户最新允许原生发光贴图限定局部光纹和受控 Bloom；不实现全局光照、逐层发光传输或完整多次折射。
- 侧面观察须能看到内嵌紫色，不呈现只有正反面有色、中心镂空的观感；修正实现及近似边界见 [[日志/2026-09-03-修复侧面内嵌紫色缺失|侧面内芯修复日志]]，不据此改写源 Blender。
- 用户进一步要求正侧面不得因不同补色规则额外饱和，顶部颜色须在内胆边界连续闭合；修正见 [[日志/2026-09-03-统一内胆着色并修正顶部紫色越界|内胆闭合与着色修复日志]]。
- 用户要求外体与内体四角有轻微可见的轮廓，以辨认侧面厚度，不要过于明显；本次实现与调校见 [[日志/2026-09-03-添加外壳与内胆柔和轮廓|柔和轮廓日志]]。
- 启动采用已调好的深邃预设和用户指定的 Citrus Orchard EXR；支持替换 HDRI，背景图片可独立隐藏。清除后仍为纯白背景与均匀白色环境。全局环境强度乘各槽原有强度。
- 阵列使用网页场景 XYZ；最多 8 层、单层 1–100 份、合计最多 256 份。整组仍为单网格两个材质分组，两套材质控制作用于所有副本。
- 用户要求紫色深浅由实际切片叠加产生，而不是按副本编号涂色；同时关注 HDRI 背景下的分级可见性。实现与视觉取舍见 [[日志/2026-09-03-实现切片颜色累积与HDRI分级显色|切片累积工作日志]]。
- 图片仅在浏览器读取；图片、材质与阵列参数均不持久化，刷新恢复默认。不写回 Blender 或导出阵列模型。
- 视角采用 Three.js 默认 Y-up 相机轴系；模型根节点负责适配 Blender 原始正面轴向。
- 默认不自动旋转，鼠标和触控由 OrbitControls 操作。

## 质量约束

- 保持按需渲染；参数变化、相机变化、资源加载和窗口缩放时才重绘。
- React 卸载时必须销毁 GUI、控制器、材质、几何体、纹理和渲染器。
- 完整任务需执行相关构建和交互验证。

## 操作边界

- 保留 Blender 原件、示例源码、视频和远端已有资产。
- 按 [[知识/规范/Git任务提交约定|Git 任务提交约定]] 完成提交和推送。

# 当前约束

## 技术约束

- 页面技术栈为 React + Vite + Three.js + WebGL。
- 开发地址、React 壳、Canvas 和 WebGLRenderer 保持唯一；场景1至场景6使用六个隔离的 `THREE.Scene`，只有活动场景进入其专属更新与渲染管线。
- Three.js 核心使用 `source/threejs-transmission/build/three.module.js`；运行时不依赖 CDN。
- GLB 必须保留 `SPECIMEN_FRAME_MATERIAL_SLOTS` 对象名，以及外框槽位 0、内框槽位 1。
- 标本主体为一个 Mesh 和两个材质分组；两个槽位分别拥有独立 `MeshPhysicalMaterial` 和参数对象，不得共享材质状态。用户新增的背景与尽头亮心作为独立呈现对象管理，不并入标本材质区域。
- 材质与控制继续基于本地 `source/threejs-transmission`；源材质仅提供初始颜色，不导入其 Alpha、粗糙度、IOR 或透射参数。用户后续要求研究并实现切片颜色随重叠逐级加深，允许为此扩展显示逻辑，但不擅自改两槽原色或替换框架。

## 交互与界面约束

- 页面只显示全屏模型、原生 lil-gui 中文参数面板和加载失败提示，不添加额外装饰界面。
- 根面板提供“场景1·标本纵深 / 场景2·花粉星云 / 场景3·金菊闪柳烟花 / 场景4·无限花开 / 场景5·纸飞机环游 / 场景6·蝶翼”选择；切换时隐藏非当前场景的专属面板，分别保留相机角度。
- 场景2必须保留远层微尘、中层花粉、近层花瓣和中央能量核心；三层数量上限分别为 4000 / 1200 / 300，使用批量几何与 GPU 动画，不创建每粒独立 Mesh。
- 场景1与场景2共用 HDRI 纹理、程序混色背景的配色与时间；场景2不得读取标本切片覆盖、透明排序或局部 Bloom 代理。
- 场景3必须拥有独立夜空配色、时间线和 Bloom，不得改写场景1/2的梦境背景参数；烟花固定使用 GPU 批次与 draw range，不按粒子创建独立 Mesh。HDRI 继续保留给物理材质，场景3自定义粒子不依赖 HDRI 照明。
- 用户后续指定参考指尖烟花网站与彩色花火视频深度改造场景3，并明确要求支持 Three.js 旋转；不得因参考站是二维绘制而取消旋转。实现及验证见 [[日志/2026-09-05-深度改造场景3为可旋转指尖彩色花火]]。
- 场景3当前只验收桌面浏览器完整效果，不新增移动端性能适配。
- 场景4保留杜鹃花真实花瓣与原纹理；用户最新要求按独立花瓣年龄持续展开，让最老外瓣脱离后向右下方翻转飘散。禁止以整花冠缩小回收代替脱落，也不倒放闭合；旧“单个完整花冠实例”的限制被 [[决策/ADR-013-无限花开按花瓣年龄展开与脱落|ADR-013]] 替代。
- 场景4继续使用 WebGL 与共享 HDRI 环境照明；独立花园背景不得替代 HDRI。当前现有着色器和后处理不因该场景整体迁移 WebGPU。
- 材质分组名称为“外框插槽管理”和“内框插槽管理”。
- 使用 `source/Specimen_Frame_Transparent.blend` 的几何与底色：外框 `#f3faff`、内框 `#d1aaff`。不自动导入源文件其他物理材质参数。
- 两槽独立提供原生自发光颜色和强度（0–10、步长 0.01），不乘环境强度或层数。用户最新允许原生发光贴图限定局部光纹和受控 Bloom；不实现全局光照、逐层发光传输或完整多次折射。
- 侧面观察须能看到内嵌紫色，不呈现只有正反面有色、中心镂空的观感；修正实现及近似边界见 [[日志/2026-09-03-修复侧面内嵌紫色缺失|侧面内芯修复日志]]，不据此改写源 Blender。
- 用户进一步要求正侧面不得因不同补色规则额外饱和，顶部颜色须在内胆边界连续闭合；修正见 [[日志/2026-09-03-统一内胆着色并修正顶部紫色越界|内胆闭合与着色修复日志]]。
- 用户要求外体与内体四角有轻微可见的轮廓，以辨认侧面厚度，不要过于明显；本次实现与调校见 [[日志/2026-09-03-添加外壳与内胆柔和轮廓|柔和轮廓日志]]。
- 用户最新要求按两段视频实现尽头迎光、慢速粉紫—奶黄背景及材质改善，见 [[决策/ADR-007-视频参考梦境环境与柔透呈现|ADR-007]]。启动采用梦境呈现，原 Citrus Orchard EXR 照明与 HDRI 控制保留。手动选图成功或清除后切回图片/纯白背景，混色可重新选用；全局环境强度仍乘各槽强度。
- 用户进一步要求评估完全删除 HDRI，并明确若影响模型质感或显示则不要删除。运行时 A/B 证明两槽 `MeshPhysicalMaterial` 的环境反射与高光仍受 HDRI 影响，因此 HDRI 面板、加载器、内置 EXR、双槽强度和资源清理必须继续保留；梦境程序背景不能视为材质环境照明的等价替代。见 [[日志/2026-09-04-评估HDRI移除并决定保留|HDRI 移除评估]]。
- 用户要求移除阵列修改器，唯一纵深入口范围 1–200（含首层），沿网页世界 −Z 排列，保留间距与适配全部。整组仍为单网格两个材质分组，两套材质控制作用于全部切片；见 [[决策/ADR-008-统一纵深控制与无限远亮心|ADR-008]]。
- 亮心默认可用无限远太阳表现；保留有限距离参数，不设置 Infinity 坐标。背景流动速度 0–2（0 暂停）。面板只做轻量用途分组，不删改其他参数。
- 光束显隐只由太阳相对相机视口的位置驱动；正常画内须完整显示，跨越边缘须按可调空间软带和时间响应连续淡入淡出，不得瞬间跳变。纵深数量、间距、75° 极限取景、镜头夹角或光束扩散值不得形成额外显隐门限；显式关闭效果或亮心强度为 0 可立即生效。
- 用户要求紫色深浅由实际切片叠加产生，而不是按副本编号涂色；同时关注 HDRI 背景下的分级可见性。实现与视觉取舍见 [[日志/2026-09-03-实现切片颜色累积与HDRI分级显色|切片累积工作日志]]。
- 图片仅在浏览器读取；图片、材质与纵深参数均不持久化，刷新恢复默认。不写回 Blender 或导出阵列模型。
- 视角采用 Three.js 默认 Y-up 相机轴系；模型根节点负责适配 Blender 原始正面轴向。
- 默认不自动旋转，鼠标和触控由 OrbitControls 操作。
- 默认启用轻量鼠标三维视差；空闲时仅在绘制期间临时作用于相机。轨道交互开始时必须从当前可见姿态无跳变接管，不得先回到隐藏基础姿态；交互期间不得叠加指针运动，结束后默认以松手位置为临时中性点。鼠标离开后缓动回中，减少动态偏好下停用；见 [[决策/ADR-009-指针驱动三维相机视差|ADR-009]]。

- 用户指定场景5使用 `source/papierfliegerswap.blend` 与地球模型包，在原开发服务器呈现大量纸飞机按路径环游星球；参考视频、Paper Planes 与 Three.js 官方资料。实现选择见 [[日志/2026-09-05-新增纸飞机环游星球场景]]。
- 用户指定场景5正式展示前先用单架纸飞机引导相机跟随入场，最终带到星球场景；实现选择见 [[日志/2026-09-05-增加纸飞机跟随入场镜头]]。此前默认自由视角要求不限制这段用户指定的入场运镜。
- 用户进一步要求场景5参考场景1的纵深感，增加云、轻微太阳效果，并丰富飞机相对相机的入场运动；本轮方案见 [[日志/2026-09-05-丰富纸飞机云层阳光与跟飞动势]]。

- 用户指定建模蝴蝶并在下一个场景展示扇翅动画；实现为场景6，见 [[日志/2026-09-05-建模蝴蝶并新增扇翅动画场景]]。

- 用户指定场景6按参考图采用奶白玫瑰红轮廓与细节，身体更细致，上翻更充分并修正穿模；前后翅应连续衔接，不能用横向镂空间隙避让。见 [[日志/2026-09-05-按参考重做玫瑰蝶并修复翅膀衔接]]。

- 用户进一步要求场景6补实身体附近的翅根连接、增加前翅上缘饱满度，并让左右翅膀的斑纹细节避免完全镜像。实现与验证见 [[日志/2026-09-05-补实蝶翼连接并丰富非镜像细节]]。

## 质量约束

- 用户指定场景6使用场景1同款背景及迎光光束，默认蝴蝶水平放置、头朝光源；见 [[日志/2026-09-05-蝶翼共享梦境背景并水平迎光]]。

- 用户指定场景7参考 Microsoft AI 网站及演示视频复现指针驱动的斑驳光影；不因已有场景采用三维技术而把参考效果改为可环绕的三维景物。具体实现与未确认的美术参数见 [[日志/2026-09-05-新增微软参考二维斑驳光影场景7]]。

- 静态或暂停背景时保持按需渲染；用户指定的实际背景动画在页面可见且开启动画时绘制，后台暂停，尊重减少动画偏好。
- React 卸载时必须销毁 GUI、控制器、材质、几何体、纹理和渲染器。
- 完整任务需执行相关构建和交互验证。

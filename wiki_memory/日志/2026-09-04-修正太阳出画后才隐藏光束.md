# 修正太阳出画后才隐藏光束

## 目标

按用户三张视角参考修正迎光机制：75° 极限侧视时，只要太阳圆盘仍在相机画面内就必须显示光束；只有太阳完全移出画面后才隐藏。纵深数量和间距不参与显隐。

## 实现

- `src/viewer/dreamAtmosphere.js` 移除原 32° 镜头朝向、65° 世界轴对齐和边缘提前淡出的三重门限。
- 太阳投影返回 UV、屏幕半径和深度；显隐只检查圆盘与视口相交、有限模式裁剪深度及是否位于相机前方。圆盘部分出画仍保持 gate=1，完全出画后 gate=0。
- 原“迎光角度范围”改为“光束扩散范围”，只调整径向光在屏幕上的衰减距离，不再影响光束是否显示。太阳出画后同步跳过太阳 Bloom。
- 面板说明同步新规则；模型、双槽材质、纵深几何和默认色值未改。

## 验证

- `npm test`：33/33 通过，新增 75° 斜视、圆盘部分出画、完全出画和相机背后边界。
- `npm run build`：通过；仅保留原有主包超过 500 kB 提示。
- `browser-infinite-depth.mjs`：真实浏览器确认 75° 时太阳 UV x≈0.123、gate=1；继续转出画后 UV x≈−0.254、gate=0。光束扩散 0.3/1 均不改变显隐。
- 同一规则在 200 层、间距 10、末层深度约 2004.7 的场景再次通过；圆盘在画面内 gate=1，出画后 gate=0。截图确认前者有圆盘与径向光，后者只剩动态混色背景。

## 结果与边界

这是基于屏幕投影的迎光显隐，不是体积散射或真实遮挡求交。圆盘任意部分与视口相交即完整保留光束，完全离开后关闭，不做靠近边缘的提前淡出。关联决策：[[决策/ADR-008-统一纵深控制与无限远亮心|ADR-008]]。

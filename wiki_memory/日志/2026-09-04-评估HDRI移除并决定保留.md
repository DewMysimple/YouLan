# 2026-09-04｜评估 HDRI 移除并决定保留

## 目标

评估梦境程序背景启用后能否完整删除 HDRI 面板、加载器、资源与材质绑定；用户明确要求：若删除会影响模型质感或显示，则不要删除。

## 评判

- 梦境背景由 `dreamAtmosphere.js` 的 ShaderMaterial 生成，负责可见的粉紫—奶黄背景、太阳与迎光效果，本身不依赖 HDRI。
- 标本的两个 `MeshPhysicalMaterial` 仍显式使用同一 HDRI 作为环境照明与反射来源；程序背景参与透射画面，但不等价于材质环境反射。
- 场景2的粒子和能量核心主要使用自定义 Shader，不依赖 HDRI；这不改变场景1材质的依赖。
- 因此，完全删除 HDRI 会改变边缘高光、镜面响应及粗糙度/物理对照下的外观。普通灯光只能提供另一种照明结果，不能证明视觉等价。

## 验证

- 在同一浏览器、固定梦境背景和相机下，仅在运行时清空 `scene.environment` 与两槽 `material.envMap`，不写入工程。
- 默认 16 层正面样本中背景像素保持一致，模型区域已出现 RGB 差异；单层斜视样本局部最大平均 RGB 通道差约 13.7，证明环境反射确实参与模型显示。
- `npm test`：41 / 41 通过。
- `npm run build`：通过，仅保留既有的大包体积提示。
- 撤销评估期间的所有未提交清理改动后，`src/`、`tests/`、`public/` 与 `scripts/` 均与 `HEAD` 一致；两个 EXR 资源、环境管理器及面板完整保留。

## 结果

按用户条件决定不删除 HDRI。开发服务继续保留 HDRI 环境设置、内置 EXR、替换/清除能力、双槽环境贴图强度及现有资源释放逻辑；梦境背景仍是默认可见背景。

## 文件范围

- 运行时代码与资源：无最终变更。
- 仅新增本评估日志并同步当前状态记忆。

## 遗留边界

- 若未来希望去除 HDRI，必须先设计并验收可替代的程序化 IBL 或灯光方案，进行正面、斜视、侧面及物理对照的视觉基准比较；不能把“背景看起来相同”视为“材质照明等价”。

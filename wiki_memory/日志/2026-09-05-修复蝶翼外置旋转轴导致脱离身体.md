# 2026-09-05｜修复蝶翼外置旋转轴导致脱离身体

- 目标：用户从沿身体纵轴的端面视角指出扇翅时翅膀脱离身体，要求固定轴连接。
- 关联：[[当前状态/当前约束]]、[[日志/MOC_工作日志]]。

## 原因与修复

- 旧版翅根轴位于身体两侧 x=±0.160，肩部中心在±0.078。旋转节点自身没有平移动画，但轴在肩部之外；加宽的翅膜只能在平展时遮住间隙，上翻后仍绕外置轴离开身体。
- 将四个翅根旋转轴移到肩部内部 x=±0.078，仍沿身体纵向旋转。翼面局部坐标反向补偿0.082，保留此前展开轮廓、连接面积、UV、左右独立纹理及前后翅层间距。
- 循环时长、82度上翻、43度下压、悬停和控制面板保持原行为。
- 文件：`scripts/build_butterfly.py`、`source/Blue_Morpho_Butterfly.blend`、`public/models/blue-morpho-butterfly.glb`、`tests/butterfly.test.js`、`tests/browser-butterfly.mjs`。

## 验证

- 新增实际连接检查：5档权重，每档121个周期采样，四个旋转轴相对身体位置保持固定且位于肩部内部；每片翅膀每个采样均有至少8个真实翼面顶点持续嵌入对应肩部椭球。
- 继续检查前后翅的旋转深度层不相交；自由翼面改为三维径向间距检查，正确区分合拢后向身体背部伸展与真正进入身体。
- 用上一提交的旧GLB运行同一测试，按预期在“axis remains inside the shoulder”断言失败；新版通过。回归材料在本地 `artifacts/wing-joint-regression.test.mjs` 和 `artifacts/old-butterfly.glb`，不提交。
- `npm test`：60/60通过；`npm run build`通过，既有主包大小提示仍在。
- 浏览器套件新增端面上翻、中间与下压姿态截图，目视确认翼面从身体两侧连续伸出，无旧版根部悬空。
- 既有纹理解码、暂停、速度0、重试、资源切换、相机状态、页面隐藏与减少动态偏好检查全部通过，控制台错误为空。
- 默认25次绘制、87082个三角形；证据在本地 `artifacts/butterfly-fixed-axis/verified/`。
- 原开发服务器与浏览器检查端口当时已停止，已重新启动本地5173开发服务及隔离的无头浏览器检查实例。

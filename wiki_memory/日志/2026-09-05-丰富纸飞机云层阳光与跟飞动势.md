# 2026-09-05｜丰富纸飞机云层阳光与跟飞动势

- 目标：用户指出场景5入场的渐变背景与飞机相对镜头运动太平淡，要求参考场景1的标本纵深感觉，加入云和少量太阳效果，丰富天空与跟飞体验。
- 日志索引：[[日志/MOC_工作日志|工作日志 MOC]]
- 前置：[[日志/2026-09-05-增加纸飞机跟随入场镜头]]、[[日志/2026-09-05-新增纸飞机环游星球场景]]。

## 已确认方向

- 场景5需要有云、轻微太阳效果和更丰富的空间层次。
- 飞机不应始终固定在相机画面中，跟飞入场需要更明显的相对运动。
- 参考场景1的纵深与柔光呈现，仍在场景5中实现。

## 本轮实现选择

- 新增独立天空模块，替代原固定屏幕渐变。通过相机逆投影与世界旋转重建视线，天空和固定方向太阳跟随真实相机视角变化；太阳包括柔边圆盘、暖色外晕和轻微径向光线，云层与实体会挡住背景中的太阳。
- 云分成远处天空、中景云团和入场航线附近云团，共66组、660个有不同三维位置和尺寸的柔边云块。每组云有实际纵深，使用一个 InstancedMesh；逐帧按相机空间深度排序，透明材质保留深度测试并关闭深度写入。
- 云块着色使用程序噪声柔边、近似球面明暗和微暖边缘，近裁剪区渐隐。无需新增贴图资源和网络请求；属于三维分布的朝向相机云片近似，不是物理体积散射或光线步进云。
- 云团缓慢漂移，沿用场景5播放、速度、页面可见性和减少动态偏好。场景5暂停后按需渲染，离开场景停止时间，现有根节点负责统一释放实例、几何和材质。
- 原生中文面板新增“显示云层”“云层浓度”“云层流动”“太阳柔光”，重置恢复本轮默认；原色彩、环游和入场控件保留。
- 跟飞路径增加爬升和下探，领航飞机叠加衰减的横摆、升沉、俯仰、偏航和侧倾；相机跟随更平稳的引导路径，并使用略滞后的方向、变化的跟随距离及轻微镜头侧倾。最后仍平滑衔接真实领航实例和正式视角。
- 云密度、色彩、太阳强度和动作幅度为本轮视觉方案，等待用户验收，不作为已确认长期默认值。

- `tests/browser-paper-intro.mjs`、`tests/browser-paper-orbit.mjs`：新增控件、云实例与常态绘制预算验证。

## 验证和结果

- `npm test`：57项通过。新增验证云团覆盖正负世界纵深、660云块在两种相机方向下正确排序、零时间增量冻结、开关生效；验证入场早期领航飞机在画面内有横向/纵向运动且与相机距离变化超过1个世界单位，原避球和末帧交接测试通过。
- `npm run build`通过；保留既有主包超过500KB的构建提示。
- 浏览器入场：默认视差开启下自动入场、重播、跳过、重置、中途切换、减少动态偏好、刷新直达均通过；云开关、云浓度与太阳强度控件通过，无控制台错误。
- 原场景5回归：2400/10000/0飞机、加载失败重试、路径控制、暂停按需绘制、相机操作与保存、重复切换资源稳定通过。默认7次绘制；关闭云为6次；10000飞机并显示路径为8次。
- 本机90帧浏览器采样平均约5.52ms，不据此承诺其他设备性能。
- 截图与报告位于 `artifacts/paper-clouds/verified/` 和 `artifacts/paper-clouds/regression/`，测试产物未纳入提交。已检查单机、跟飞、星球入画与正式视角。
- 工程记忆索引与检查通过；提交前校验任务范围并同步远端。

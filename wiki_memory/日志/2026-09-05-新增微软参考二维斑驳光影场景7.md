# 2026-09-05｜新增微软参考二维斑驳光影场景7

- 目标：结合 Microsoft AI 网站和用户本地演示视频，在场景7实现指针移动驱动的斑驳光影。用户指出效果可能并非三维景物。
- 索引：[[日志/MOC_工作日志|工作日志 MOC]]。
- 前置：[[日志/2026-09-05-建模蝴蝶并新增扇翅动画场景]]、[[决策/ADR-010-双场景隔离与共享背景]]。

## 参考与分析

- 检查用户视频：4.76秒、2552×1354、24帧/秒；按秒抽帧并对照原站运行画面，确认珊瑚色底、倾斜暖橙光斑、指针驱动的聚散和散焦软边。
- [Microsoft AI 首页](https://microsoft.ai/) 的 `block-gl` 使用正交平面，按光照范围、正弦变形、拉伸 Voronoi 分块、散焦和颜色合成的顺序绘制。网页文字和品牌导航不属于本次光影效果交付。
- 检查当日公开入口 `BlockGL-Bhdyq-8X.js` 和实际运行参数，参考默认配色、44°倾角、光照半径和指针阻尼；无需模型、HDRI 或透视相机。

## 实现选择与范围

- `src/viewer/dappledLightShaders.js`：独立编写屏幕空间光影场、50采样散焦和最终颜色合成；将原站的三次场混合合并为解析计算。背景使用本地程序色彩渐变替代原站图片，不下载运行时素材，不依赖外部网站。
- `src/viewer/dappledLightScene.js`：独立二维控制器、正交满屏平面、两个离屏目标和三个绘制步骤；前两步使用半CSS分辨率，离屏尺寸上限1280×720。输出阶段轻微重建过滤减少放大后的采样毛边；直接输出显示色，绕开三维场景曝光与ACES。
- 指针坐标以Canvas范围映射到UV，使用帧率无关阻尼；支持鼠标和主触点，离开、取消或窗口失焦后回中。关闭流动或速度为0时，指针稳定后停止连续绘制。后台、非活动场景和减少动态偏好停止时间推进。
- `src/viewer/createSpecimenViewer.js`、`sceneSwitcher.js`：接入场景7独立渲染，跳过三维相机视差并临时关闭OrbitControls；返回原场景恢复轨道操作和相机。场景7不进入共享环境管理器。支持 `?scene=dappled` 和 `?scene=7` 直达。
- `src/viewer/panelOrganization.js`：沿用原生中文lil-gui，提供指针、流动、光斑形态、散焦、颜色和恢复参考效果；场景7隐藏HDRI、三维视差和梦境背景面板。
- `tests/dappledLight.test.js`、`tests/browser-scene7.mjs`：时间/阻尼单测与真实浏览器交互、隔离和清理验证。
- 使用交互细节技能审视缓动可打断、离开回中、减少动态和按需绘制；沿用原有样式体系，未增加界面框架。

- `npm test`：62项通过，包括新加的3项二维时间、指针和减少动态测试，以及场景6既有测试。
- `npm run build`通过；保留既有主包大于500KB的提示。

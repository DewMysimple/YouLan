# 2026-09-03｜统一内胆着色并修正顶部紫色越界

- 目标：用户提供五张侧视图片，指出正侧面饱和度不同、顶部多出不与内胆闭合的紫条，要求判断来源并修复。
- 范围：修正上一版内嵌色体扩展，保留 Blender、运行时 GLB、双槽原色、独立材质和既有默认呈现。
- 日志索引：[[日志/MOC_工作日志|工作日志 MOC]]；用户目标见 [[决策/ADR-006-深邃默认呈现与局部光晕|ADR-006]]。

## 诊断与依据

- 当前 GLB 仍为闭合外壳，没有新增悬浮几何。额外紫条来自上一版 `embeddedCore.js` 的侧面补色。
- 旧扩展只在外框侧面使用折射射线，正面沿用原生着色。侧射线折向内胆，把颜色映到外框顶部；透明前框又不参与修正，因此内胆顶面不能连续接回正面。
- 旧侧面按有界路径长度额外提升颜色幂次，正面由原生正面/背面预遍次着色，两套规则造成侧面额外饱和。此前只验证侧面“有紫色”，没有检查斜视闭合和正侧面一致；本轮补足这些验收。
- 查阅官方 [MeshPhysicalMaterial](https://threejs.org/docs/pages/MeshPhysicalMaterial.html)、[透明度手册](https://threejs.org/manual/en/transparency.html)、[WebGLRenderer r185](https://github.com/mrdoob/three.js/blob/r185/src/renderers/WebGLRenderer.js) 与 [透射着色器](https://github.com/mrdoob/three.js/blob/r185/src/renderers/shaders/ShaderChunk/transmission_pars_fragment.glsl.js)，并检查实际本地 ShaderChunk。原生厚度/衰减不会自动解释嵌套色体；闭合投影是工程近似，不是官方体积追踪。

## 修正

- 所有外框可见面使用同一直线可见性射线与内胆相交，包括透过前框能看到内胆顶部的区域。范围来自原内框分组，不扩大内胆或改顶点，不恢复重叠内部壁。未穿过内胆不补色。
- 去掉侧面长路径加深，按前后两界面的同一颜色因子补足贡献。退出正反面时，原生背面预遍次已有一次内胆颜色，仅补缺失的一次；退出侧面时补两次。保留外表面正常光照与反射差异。
- 补色在切片累积之前执行，避免重新采样覆盖累积。计数代理使用同一闭合投影，把对应外框 R 分类改成内框 G，而不是重复加一个计数。
- `corePosition` 保持副本局部坐标，材质与计数共享状态。不增加 Mesh、纹理或绘制遍次；对照开关、按需渲染和清理接口保留。
- 面板只更新说明为“闭合投影近似，不模拟内部多次折射”，不增加控件或修改样式。
- 代码：`src/viewer/embeddedCore.js`、`sliceAccumulation.js`、`createSpecimenViewer.js`、`depthPresentation.js`；测试：`tests/embeddedCore.test.js`、`browser-core.mjs`、新增 `browser-core-closure.mjs`。

## 边界与保留

- `.blend`、GLB、Blender 仓库及本地 Transmission 核心未修改。原色仍为外框 `#f3faff`、内框 `#d1aaff`，显示仍为单 Mesh、双分组。保留三个旧 Blender 文件的用户删除，不纳入提交。
- 适用于当前矩形内胆、局部 X 厚度和仅平移阵列。闭合投影主动不折射内部轮廓；原生背景折射和外层反射仍存在，不承诺完整嵌套介质与递归传输。
- HDRI 下不同朝向仍可能有不同亮度、反射和最终像素；修正的是额外侧面饱和与越界，不把不同朝向强制涂成一样的平面色。

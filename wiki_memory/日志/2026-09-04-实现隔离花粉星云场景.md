# 2026-09-04｜实现隔离花粉星云场景

## 目标

把当前标本纵深作为场景1，在同一开发页面增加场景选择器、独立场景2、三层花粉粒子与中央能量核心，同时复用原有 HDRI 和程序混色背景。

## 实施

- `createSpecimenViewer.js` 现在管理标本与花粉两个独立 `THREE.Scene`，根据活动场景选择标本后处理管线或粒子直接管线。
- 新增 `sceneSwitcher.js`，提供中文场景选择、当前视角重置、场景专属面板显隐，并独立保存两套相机/OrbitControls 状态。
- 新增 `pollenScene.js`：预分配 4000 微尘、1200 花粉和 300 花瓣的批量几何，默认显示 2200 / 620 / 120；动画、形状、漂浮和漩涡由 GPU 着色器驱动。
- 中央能量核心为相机对齐的独立 ShaderMaterial，包含呼吸、柔晕、弱环与辐条；粒子使用普通透明混合保留粉紫颜色，避免在亮背景上全部溢出成白色。
- `environmentManager.js` 支持一份环境资源同步多个 Scene；`dreamAtmosphere.js` 增加共享背景网格，只共享背景输入，明确隔离标本覆盖计数。
- 场景2面板可调三层数量、三色、速度、漂浮、漩涡、整体尺寸、粒子柔光和核心强度/大小，并提供重置。

## 验证

- `npm test`：41 / 41 通过；新增多场景环境同步、共享背景隔离、粒子几何确定性、三层 draw range、动画和释放测试。
- 场景2浏览器专项通过：两 Scene 无交叉对象，环境纹理同一，共享背景不读取切片覆盖；三层默认/上限数量正确，切换相机状态恢复，暂停后回到按需绘制，反复切换 GPU 资源数稳定，移动端面板可滚动。
- 场景1回归通过：200 层与 75° 太阳边缘、梦境背景、粒子切换后标本恢复、指针视差和资源稳定。
- 生产构建通过；仅有既有的大包体积提示。

## 结果

同一页面现在可在场景1标本纵深与场景2花粉星云之间隔离切换，背景和 HDRI 保持连续，场景专属几何、动画和面板不串联。

## 遗留边界

- 场景2是艺术化 GPU 流场，不是流体或粒子碰撞模拟。
- 中央核心是屏幕对齐发光图元，不实现全局光照。

# 2026-09-03｜替换单网格双材质槽模型

- 时间：2026-09-03（北京时间）
- 类型：`feature`
- 状态：完成
- 目标：将用户提供的单网格双材质槽模型接入本地 Vite 查看器，保持两个独立材质控制及现有渲染框架。
- 日志索引：[[日志/MOC_工作日志|工作日志 MOC]]

## 已确认的决策

- 用户确认保持单网格，外框、内框分别管理两个材质槽，面板名称为“外框插槽管理”和“内框插槽管理”。
- 用户确认本地 Vite 交付，材质与控制继续基于 `source/threejs-transmission`，不改变渲染逻辑和框架。
- 用户确认执行计划：仅继承新源材质的颜色，不复制其 Alpha、粗糙度、IOR 或透射参数。
- 新架构记录于 [[决策/ADR-003-单网格双材质槽接入|ADR-003]]，原双对象绑定决策保留为历史。

## 检查与操作

- 检查源模型：一个网格，外框槽位 0 使用 12 个四边形面，内框槽位 1 使用 2 个四边形面。
- 修正导出目标及材质导出设置，保持选择导出和既有坐标约定。
- 检查本地 GLTFLoader：两个材质 primitive 会生成两个子网格，因此在加载阶段按材质名称合并成一个 Mesh、两个 geometry groups，并释放中间几何资源。
- 保留源法线与局部变换，创建两个独立 Transmission 材质；GUI 颜色初值经现有颜色管理转换为外框 `#f3faff`、内框 `#d1bfff`。

## 文件变更

- 新源资产：`source/Specimen_Frame_Shared_Topology_Material_Slots.blend`。
- 更新运行时资产 `public/models/specimen-frame.glb` 和导出脚本 `scripts/export_specimen.py`。
- 新增模型接入模块 `src/viewer/specimenModel.js`；更新查看器的材质绑定、颜色初值及分组名称。
- 同步当前状态、模块知识、导出流程和架构决策；未修改本地 Transmission 源码、React 壳层、样式或 Vite 配置。
- 任务开始前已存在的 `source/Specimen_Frame_Transparent_Merged.blend` 删除保持原状，不纳入本任务提交。

## 测试与验证

- Blender 后台导出通过；生成的 GLB 恰好包含一个节点、一个网格、两个材质 primitive。
- `npm run build` 通过；仍有既有的单包体积提示。
- 真实 Chrome 无头浏览器检查通过：一个 Canvas、一个 GUI、一个运行时 Mesh；groups 分别有 72、12 个索引，对应 24、4 个三角形。
- 实际操作两个 GUI 颜色控件及外框粗糙度，确认独立材质区域不联动；截图核对外框红色、内框绿色的区域映射正确。
- 两个材质均为 MeshPhysicalMaterial；除颜色外，透射率、不透明度、粗糙度、IOR、厚度均保留原始默认值。
- 空闲时渲染计数不增长；参数修改触发重绘；水平拖动触发相机水平环绕；HDR 同时用作环境和背景。
- 验证 primitive 子节点顺序反转后仍正确匹配材质槽；缺少对象、缺少材质槽均拒绝加载。
- 页面、控制台和网络请求无错误。

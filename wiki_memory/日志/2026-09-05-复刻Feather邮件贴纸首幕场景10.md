# 2026-09-05｜复刻Feather邮件贴纸首幕场景10

- 目标：用户指定参考 `https://feather.computer/`、本地 `PixPin_2026-09-05_20-10-16.mp4` 及截图，在下一个场景复刻第一幕；明确不要之后的内容。
- 索引：[[日志/MOC_工作日志]]；前置：[[日志/2026-09-05-接入ThreeUI狮城手记场景9]]、[[决策/ADR-010-双场景隔离与共享背景]]。

## 参考分析与范围

- 视频时长8.777秒，2560×1318、24fps；提取每0.5秒画面组成18帧对照图，核对散开、旋转收拢、环绕和单封邮件浮出状态。
- 读取源站 HTML、首屏 CSS 与公开部署脚本，真实浏览器访问源站。首幕是 DOM 贴纸与 Web Animations 动画，中央角色为源站命名的纸绘猫头鹰；不转成可环绕三维景物。
- 收拢由中央 “Got Mail?” 的悬停触发，离开散开；首屏之后的收件箱、表格、打印机、人物、抽屉和页脚均不接入，点击不启动外站账户操作。

## 实现

- 新场景10“纸间来信”；`src/viewer/featherScene.js`、`src/viewer/feather/feather.css` 和 `cards.json` 管理独立 DOM 首幕、22张贴纸、中心按钮、猫头鹰及参数面板。
- `public/feather/` 本地保存原PNG、原字体和SVG。猫头鹰提取原首幕 SVG，并嵌入头部图案以使外部 SVG 图片完整独立显示；保留录屏中的停驻状态。`source/feather-first-scene/` 记录来源、派生说明和素材 SHA-256，不声明未经确认的上游许可。
- 保留桌面原百分比布局、白底浅点阵、虚线胶囊、英文贴纸原画及字体。默认聚散600ms、3秒一圈、纵向压缩0.3、环绕缩放0.12；随机邮件400ms浮出、800–1400ms停留、350ms归队。快速反向从当前可见变换接续。
- 桌面悬停收拢/离开散开，点击可提前预览一封邮件；连续点击不会清除正在展示邮件的归队定时器。触屏轻点及键盘激活切换聚散，Escape散开；手机调整外围布局，保留44px最小按钮高度及中央角色。
- 中文参数：贴纸尺寸、聚散时长、环绕速度、环绕范围、轮流浮出邮件、点阵浓度；提供散开及恢复参考效果。
- 通过 `createSpecimenViewer.js`、`sceneSwitcher.js`、`panelOrganization.js` 接入，支持 `?scene=feather` / `?scene=10`，默认启动仍为场景1。进入折叠原面板，退出恢复原先展开状态。
- 不新增 Canvas / WebGLRenderer；活动时禁用共享轨道和视差，不绘制其他场景。首幕静止时无循环动画，后台清除定时器并暂停 WAAPI，退出或卸载清理动画，减少动态时保留完整静态画面。
- `.gitattributes` 保留素材字节，避免 Windows 换行转换影响 SVG 哈希。无新增 npm 依赖。

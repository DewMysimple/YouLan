# 2026-09-05｜接入ThreeUI狮城手记场景9

- 目标：用户指定参考 ThreeUI 的 Meng To Sketchbook 页面及随附精确源码提示词，进行本地化并添加下一个场景。
- 索引：[[日志/MOC_工作日志]]；前置：[[日志/2026-09-05-接入Codrops纵深花廊场景8]]、[[决策/ADR-010-双场景隔离与共享背景]]。

## 来源与实现

- 获取参考页面、完整注册源码包与 canonical HTML，核对六份源码和17份图片/字体的 SHA-256。原文档版本为 `e0330548b1ac905cf1b81698163ffa29f8a3a8c39b8d39f9b71ba5b9255b6dd1`；来源清单、原始文件与适配说明位于 `source/threeui-sketchbook/`。
- 精确 HTML 及资源按原路径落到 `public/landing-pages/`；保留九幅水彩、植物纸幕、18段卷页曲面、页背与阴影、原桌面快速翻阅入场、书本视差、缩放、可拖动放大镜和编辑式目录。原图内嵌字迹保持原样。
- `src/viewer/sketchbook/MengToSketchbookLandingPage.tsx` 提取原组件函数；`vendor/` 保留原 Frame、Typography、Recipe 源码。通过原组件的 applyScene 扩展入口追加本地 CSS/JS，使用用户给定的八项字体、字重、字号、字距及主色 props。未安装新依赖；不嵌入 ThreeUI 文档网站。
- `src/viewer/sketchbook/localization.js`、`.css`：中文标题“幽兰·狮城手记”、九处地名、介绍与导航；移除不适合当前项目的作者邮箱和空社交链接，页脚保留原作来源；英文原字体加本机宋体回退。默认视差为原幅度0.65，放大镜2.3倍，背景水彩浓度0.72，均有中文原生 GUI 控件。
- 修正原版关闭放大镜后仍留下放大层/隐形点击阻挡、触屏隐藏放大镜、箭头被父级指针捕获影响点击等问题；小屏放大镜缩小到108像素下限，保留触摸拖动，控制按钮40像素。英雄区裁剪防止镜柄造成横向滚动。
- `src/viewer/sketchbookScene.jsx` 将 DOM 手记作为场景9延迟挂载。原查看器仍保留唯一 Canvas / WebGLRenderer，手记活动时停用 OrbitControls / 共享视差，不运行其他场景绘制；非活动时保留文档与页码、停止 RAF，卸载时释放独立 React 根和文档。
- 进入手记时折叠原生面板并保留可展开入口，离开恢复先前展开状态；桌面右上/移动端左下沿用已有位置，折叠标签缩至132像素。通过当前场景下拉切回场景1–8，原相机姿态保留。
- 处理动态减少动画偏好、页面隐藏、拖动取消和暂停中的翻页恢复；关闭动态仍可直接翻阅、缩放和使用目录。
- 入口与接入：`createSpecimenViewer.js`、`sceneSwitcher.js`、`panelOrganization.js`、`src/styles.css`；支持 `?scene=sketchbook` / `?scene=9`，原默认启动场景不变。

## 结果与边界

- 交付场景9“狮城手记”；上述视觉默认值属于本轮适配选择，尚未作为长期设计规范确认。
- 新增手记页面与可滚动目录依据本轮用户明确提供的完整页面要求；沿用原组件的本地独立文档方式，与此前纯三维场景的呈现结构不同。
- 字体含中文系统回退，不同设备字形可能略有差别；图内字迹属于原始位图，没有重绘翻译。
- 全部运行资产在本地；页脚原作链接由用户主动点击打开外部来源。

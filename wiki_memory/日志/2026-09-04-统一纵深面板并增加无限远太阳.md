# 统一纵深面板并增加无限远太阳

## 目标与范围

实现用户指定的无限远亮心、唯一 1–200 层纵深控制、0–2 背景流动速度，轻量整理原生 lil-gui 参数。不修改模型、材质底色、不透明度、自发光默认值或切片累积公式。用户原有三个旧 Blender 文件的删除不纳入提交。

## 实现

- `src/viewer/dreamAtmosphere.js`：默认“无限远（太阳）”，方向固定世界 −Z；使用相机相对有限代理和远景深度绘制，透射场景仍能看到亮心。转动镜头会改变投影，平移/拉近不改变视角大小。保留“有限距离”、距末层 1–80 与原半径输入；无限远时距离灰显且保留数值。速度扩大到 0–2，默认 0.18 不变。
- `src/viewer/depthStack.js`：唯一纵深状态与 1–200 整数/有限间距验证，直接构造世界 −Z 偏移；复用基础双槽几何复制函数，不通过原每层上限 100 的修改器评估。连续调整在现有渲染帧中合并、释放旧几何。适时扩大远裁剪面，以包含 200 层×最大间距。
- `src/viewer/depthPresentation.js`、`createSpecimenViewer.js`：移除修改器面板及隐藏层状态；将适配全部迁入深邃效果，保留首层取景和物理/颜色对照。默认仍 16 层、间距 1.7。
- `src/viewer/panelOrganization.js`、`src/styles.css`：按深邃→梦境→HDRI→双槽→渲染排序；原控制器按用途排列，加小标题，长说明可折叠，默认仅展开深邃。保留所有非阵列参数绑定，不引入第二套 UI 或依赖。
- 测试：新增无限远/1–200 单元与真实 GUI 回归；旧 HDRI、发光、切片和内胆测试迁移新入口。无重叠/多轴产品入口后，内胆闭合和累积的特殊几何只在 `browserHarness.diagnosticCopies` 的 Vite 隔离诊断中构造，不声称是当前 UI 功能。

## 资料依据与推导边界

依据 [Three.js Camera](https://threejs.org/docs/pages/Camera.html) 的世界方向与矩阵、[PerspectiveCamera](https://threejs.org/docs/pages/PerspectiveCamera.html) 的 FOV/近远裁剪约束，实现固定方向的远景代理。太阳代理的投影与远景深度是本工程实现方案，不宣称 Three.js 自带“无限太阳”开关。不模拟真实天体尺度、全局照明、体积散射或完整多次折射。

## 面板审查（quick）

范围为 React/Vite 查看器内原生 lil-gui 与 plain CSS；使用 `make-interfaces-feel-better`，不做页面重设计。

| 类别 | 检查范围 | 结果 |
| --- | --- | --- |
| 字体 | CSS 与实际桌面数字输入 | 保留原字体和等宽数字 |
| 分区 | 原控制器、参数清单、桌面/移动截图 | 用途分组；保留原绑定；长说明折叠 |
| 动画 | 原生交互，不添加面板动画 | 速度 0/暂停仍静态，背景速度范围按需求扩展 |
| 图标 | lil-gui 原生箭头/复选框 | 不替换图标体系 |
| 性能 | 同帧几何释放、空闲计数和 GPU 资源 | 不添加 listen/新 UI 循环 |

| 级别 | 位置 | 之前 | 之后 | 原因 |
| --- | --- | --- | --- | --- |
| MEDIUM | viewerPanels / depthPresentation | 两套入口修改同一几何 | 唯一纵深入口 | 消除互相覆盖的参数来源 |
| MEDIUM | 参数面板 | 用途混排、长说明展开 | 常用优先、用途标题、说明折叠 | 降低定位参数成本 |

未采用重做材质预设或引入自定义 UI：前者超出本次调节需求，后者与原生面板约束不符。面板无新增运动，未进行 10% 动画回放；旧密集控件尺寸保留，本次不扩大为移动专用 UI。

审查结论：Approve（本次轻量分组范围）；未验证所有实体触屏设备，已验证 Chrome 移动视口、滚动定位与原生控制操作。

## 边界与交付

无限远是视角表现而非真实无穷坐标；FOV 会改变太阳的屏幕大小。发光、透射和颜色累积仍为原屏幕近似。面板设置刷新恢复默认，不写回 Blender。关联决策：[[决策/ADR-008-统一纵深控制与无限远亮心|ADR-008]]。

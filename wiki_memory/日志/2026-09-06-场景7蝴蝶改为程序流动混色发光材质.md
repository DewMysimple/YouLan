# 2026-09-06｜场景7蝴蝶改为程序流动混色发光材质

- 目标：移除场景7蝴蝶的翼面纹理，参考亮色蝴蝶图改为以亮黄、微橙为主的程序流动混色自发光材质，同时避免纯发光单色，并提供多套方案供选择。
- 日志索引：[[日志/MOC_工作日志|工作日志 MOC]]。

## 实现与文件

- `src/viewer/butterflyFlowMaterial.js`：新增无图片依赖的三色程序噪声与流动色带，扩展 `MeshPhysicalMaterial`，同一色域分别驱动物理底色和局部自发光遮罩。
- `src/viewer/butterflyScene.js`：加载模型后释放四张颜色纹理与四张法线纹理，四片翅膀分别使用带相位差的程序材质；流动和扇翅拥有独立时钟。
- 默认“晨光金蝶”采用奶黄、亮黄、微橙，另提供“柠檬萤火、杏桃日晕、蜂蜜琥珀、月白金辉、青柠暖焰”五套方案。
- 面板开放配色方案、三色、播放、速度、尺度、扭曲、色域对比与局部自发光强度；手动改色显示为“自定义”。
- 保留粗糙度、环境反射、清漆、虹彩和场景灯光，压低过曝，使非发光区域和表面明暗仍可辨认。
- `src/viewer/sceneSwitcher.js`：更新场景7状态说明。
- `tests/browser-butterfly.mjs`、`tests/browser-butterfly-flow.mjs`：覆盖无贴图运行时材质、六套方案、独立流动时钟、暂停、场景切换、资源和浏览器错误。

## 验证

- `npm test`：78项通过。
- `npm run build`：通过；仅保留既有主包体积提示。
- 场景7完整浏览器回归通过：模型加载失败重试、四片翼面无贴图、程序材质、六套配色、扇翅与流动独立暂停、背景模式、极限姿态、场景切换、页面隐藏、减少动态偏好和直接入口均通过，零浏览器错误。
- 逐套人工检查展开翼面截图；默认方案能看到奶黄底、亮黄色域和微橙流带，未呈现整片纯白或单色自发光。
- 浏览器报告与截图位于本地 `artifacts/butterfly-flow/`，不纳入提交。

## 结果与遗留

- 结果：场景7已交付六套可选的无贴图程序流动混色局部自发光翼面，默认采用“晨光金蝶”。
- 遗留：等待用户在实际播放中选择最终配色；当前六套与参数均可直接继续微调。

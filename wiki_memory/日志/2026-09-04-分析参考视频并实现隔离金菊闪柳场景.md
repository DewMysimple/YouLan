# 2026-09-04｜分析参考视频并实现隔离金菊闪柳场景

## 目标

把 `source/好漂亮一朵大菊花！景泰8寸：金菊闪柳.mp4` 拆解为可控的实时烟花阶段，在现有开发页面新增与场景1、场景2隔离的场景3；保留 HDRI，场景3使用独立可调夜空，并以桌面浏览器完整效果为目标。

## 参考拆解

- 参考视频约 11 秒、竖屏 30fps；主要阶段为金色升空尾迹、爆心过曝、约 30–45 枝金菊放射、延迟冷绿白闪烁簇、受阻力和重力影响的金橙闪柳及余烬消散。
- 实现参考 Three.js `BufferGeometry` 自定义属性、批量 `Points`、官方 `UnrealBloomPass` / `OutputPass`，并采用低分辨率后处理可选档位降低粒子过绘和 Bloom 成本。
- 主枝以连续细线批次叠加粒子亮点，解决纯点列不连贯；绿白闪烁保持独立粒子批次和枝端延迟，不创建每粒独立 Mesh。

## 实施

- 新增 `fireworkScene.js`：预分配 192 个升空粒子、5760 个主枝粒子、11376 个连续线顶点和 10000 个闪烁粒子；时间线、阻力、重力、风、三维纵深、枝数、密度、颜色和粒子参数全部由 GPU 属性与 uniform 驱动。
- 新增 `fireworkPost.js`：场景3独立线性原画、Bloom 工作缓冲与 `OutputPass`；Bloom 可关闭，质量档同时控制闪烁 draw range 和后处理分辨率。
- 场景选择器扩展为三套隔离 Scene 与三套相机状态。场景3拥有独立黑夜/梦境夜色程序背景，不修改场景1/2的梦境背景；HDRI 管理链继续保留并同步资源。
- 中文面板增加播放/时间、金菊结构、闪烁与爆心、烟花色彩、独立夜空、光晕与性能及重置分组；刷新恢复默认。
- 修正爆心烟晕反向 `smoothstep` 的未定义用法，避免晚期中心异常亮斑；粒子片元增加圆形软边和丢弃阈值，避免方块感。

## 验证

- `npm test`：43 / 43 通过。
- 场景3浏览器专项通过：三 Scene 无交叉几何，场景专属面板正确显隐，三套相机状态可恢复，暂停后回到按需渲染，质量档和 draw range 生效。
- 五阶段截图通过像素断言：背景不得成为全白后处理画面，爆心必须保持可见亮度；最终截图确认无晚期中心方块残影。
- 场景反复切换后资源稳定在 28 个几何、37 个纹理、37 个程序，没有持续增长。
- 生产构建通过；仅保留既有大包体积提示。

## 结果

同一开发页面现在包含隔离的场景3“金菊闪柳烟花”。默认高质量档呈现金色连续主枝、粒子亮点、冷绿白枝端闪烁、爆心柔光和自然下坠闪柳；用户可切换均衡或省电档。场景1的物理材质与 HDRI 行为未被删除或改写。

## 边界

- 烟花是参考实拍的实时美术近似，不是流体、烟雾体积或精确火药动力学模拟。
- Bloom 是屏幕后处理，不产生全局照明；场景3自定义粒子材质不依赖 HDRI 物理照明。
- 本轮按用户确认只验收桌面浏览器，不新增移动端性能适配。

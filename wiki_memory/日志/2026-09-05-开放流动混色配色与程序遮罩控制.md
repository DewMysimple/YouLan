# 2026-09-05｜开放流动混色配色与程序遮罩控制

- 时间：2026-09-05（北京时间）
- 状态：完成
- 目标：在控制面板开放流动混色的颜色等个性化参数，说明遮罩来源并开放相关控制。
- 日志索引：[[日志/MOC_工作日志|工作日志 MOC]]

## 已确认的需求

- 用户指定为流动混色增加更多个性化参数，例如颜色。
- 用户要求说明是否使用遮罩贴图，若有则公开相关参数。

## 实现与范围

- 代码核实：混色背景通过三维程序噪声与平滑权重生成，没有外部遮罩图片；场景1迎光另读取实时渲染的切片覆盖纹理，场景6没有该纹理。
- 新增“梦境背景与迎光 → 流动混色个性化”：三色选择、颜色2占比偏移、颜色3覆盖强度、色块大小、扭曲、过渡柔和度、图案种子、放射色带强度/数量/旋转。
- 新增两种灰度混色权重预览；预览保留模型与迎光，不是导入图片功能。
- 新增“模型遮挡影响（场景1）”0–1，控制覆盖纹理对屏幕迎光的衰减与层级保护影响；默认1沿用原有遮挡。
- 沿用现有三色和图案默认值；场景1、2、6共享新参数，场景6仍有独立太阳状态，场景2不显示太阳色带。
- 本组恢复按钮仅恢复配色、图案和预览，不重置亮度、动画、太阳或模型；刷新沿用工程既有恢复全部默认规则。
- 暂停也能编辑并按需重绘；非混色背景下禁用本组，说明使用折叠区域。

## 文件

- `src/viewer/dreamAtmosphere.js`：参数、着色器输入、共享背景、面板、恢复与说明。
- `src/viewer/panelOrganization.js`：混色组位置与模型遮挡参数排序。
- `tests/browser-flow-controls.mjs`：真实控件到像素、共享与隔离、恢复、按需渲染、资源测试。

## 验证

- `npm test`：70项通过。
- `npm run build`：通过，保留既有主包体积提示。
- 新浏览器测试通过：三色更换、6项图案参数与3项色带参数产生像素变化，两种遮罩灰度显示，固定时刻恢复默认像素一致。
- 三场景共享新参数且场景2、6不读取标本覆盖；场景1遮挡影响产生实际画面差异。
- 暂停后重回按需绘制、HDRI/纯黑控件禁用、重复调整无几何/纹理/程序增长；无浏览器错误。
- 场景1梦境回归通过：默认材质、动画/暂停、太阳出入画、实际遮挡、1–200层、HDRI、资源和后台状态。
- 报告与人工查看截图：`artifacts/flow-controls/`；场景1回归：`artifacts/flow-controls/scene1-regression/`。

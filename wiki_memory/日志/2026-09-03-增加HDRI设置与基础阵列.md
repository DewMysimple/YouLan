# 2026-09-03｜增加 HDRI 设置与基础阵列

- 类型：`feature`
- 状态：完成
- 目标：在现有面板增加可替换 HDRI 与可叠加基础阵列，保持单网格双材质槽和本地 Transmission 框架。
- 日志索引：[[日志/MOC_工作日志|工作日志 MOC]]

## 已确认决策与范围

用户在计划讨论中选择默认纯白背景和均匀白色环境光、基础阵列、多层叠加、网页直观 XYZ 坐标、仅当前页面会话保存，并明确批准完整实施计划。长期约定见 [[决策/ADR-004-HDRI与可叠加基础阵列|ADR-004]]。

## 实现

- 新增 `src/viewer/environmentManager.js`：统一图片解码、白色环境、强度乘积、背景控制和生命周期。HDR/EXR 加载器按需导入，UltraHDR 保留本地源码，并适配异步失败回调；EXR 尊重加载器的 `flipY=false`。
- 新增 `src/viewer/arrayModifier.js`：纯计算阵列评估、局部/网页坐标转换、双材质分组几何生成及保持观察方向的取景。
- 新增 `src/viewer/viewerPanels.js`：原生 lil-gui HDRI 和修改器面板，带加载、失败、禁用、零偏移与超限反馈，不使用持续监听渲染。
- 修改场景入口的加载、材质环境参数回调及清理；样式只调整白色底色、状态提示和等宽数字。使用界面细节技能保持已有样式体系，不引入新 UI 库或动画。
- 新增 Node 单元测试、真实 Chrome/CDP 回归脚本与 Blender 图片测试夹具生成器；`npm test` 为单元测试入口。
- 未修改 Blender 原件、GLB、Blender 仓库或本地 Transmission 源码。旧 `source/Specimen_Frame_Transparent_Merged.blend` 的既存删除不纳入本任务。

## 验证结果

- 8 项 Node 自动测试通过：数量、正负/相加/零偏移、逐层包围盒、顺序、数值与数量上限、双分组/属性保留、相机取景、环境强度乘积、加载失败与竞争、清除及卸载。
- 真实 Chrome 使用原生文件输入分别加载 Blender 生成的 HDR、EXR、PNG、JPG 夹具和原内置 UltraHDR；格式、尺寸与 EXR 方向标记正确。损坏 HDR 不影响现有环境或模型。
- 背景隐藏保留照明，旋转同步两槽；白背景在曝光 0.2 时实际像素仍为 RGBA `(255,255,255,255)`。
- 实际面板创建 2×3 阵列，验证单 Mesh、两个 groups（432/72 索引）及外红/内绿槽位；截图检查布局正确。
- 红绿仅为独立测试浏览器中的插槽诊断色，未写入应用默认材质。用户指出诊断截图会造成材质被修改的误解后，测试补充了原始配色截图，并断言初始颜色仍为 `#f3faff` / `#d1bfff`、原有透射率/不透明度/粗糙度/IOR/厚度完全不变。
- 8 层、256 份边界通过；超限回滚，排序、禁用、删除、重置通过；原始几何恢复一致。连续三次同帧输入只触发一次几何替换。
- 连续环境替换后 GPU 纹理数量稳定，阵列重置后 GPU 几何数量恢复；静止不持续渲染，重复卸载不残留 GUI。
- 查看前后排列的玻璃阵列效果，未扩展既有多次折射能力。移动端 390×844 面板位于视口内且内容可滚动。
- 浏览器无未捕获异常或控制台错误。生产构建通过，仍有既有主包大于 500 kB 的提示。

功能已接入本地开发服务器。图片及设置刷新即重置；不上传、不导出、不保存模型。无新增功能阻塞。按工程协议刷新记忆索引、检查并独立提交推送；具体提交号在交付回复中记录。

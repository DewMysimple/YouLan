# 2026-09-06｜重构左右参数栏与参数撤销

- 目标：用户要求场景选择与公共跨场景同名参数位于左栏，单场景详细参数位于右栏；深入排查不生效、无关参数；增加可靠默认恢复、Ctrl+Z 撤销和参数面板收起/展开。
- 日志索引：[[日志/MOC_工作日志|工作日志 MOC]]。

## 检查结论与归属

核对 `createSpecimenViewer.js` 的各渲染分支、`sceneSwitcher.js` 的旧显隐规则、各场景面板绑定及实际材质/着色器更新。旧规则把梦境、视差与 HDRI 统一展示给多个三维场景，但它们的渲染能力并不相同。

| 当前编号 / 场景 | 左栏实际共享能力 | 专属参数与处理 |
| --- | --- | --- |
| 1 纸纹序章 | 场景选择 | 右栏开场时长、圆形与纸纹；时长在对应动画阶段生效 |
| 2 标本纵深 | 梦境与迎光、指针视差、HDRI、曝光 | 右栏纵深、两槽材质、切片与透射质量；遮挡和紫色层级保护只在此场景提供 |
| 3 花粉星云 | 梦境背景、指针视差、HDRI 图片背景、曝光 | 隐藏迎光、放射色带和材质环境强度；粒子使用自定义着色器，不采样 HDRI 照明 |
| 4 指尖花火 | 曝光 | 左栏同名播放、时间、天空参数保留各模式数值；右栏花火细节，原版/彩色模式显隐随切换更新 |
| 5 无限花开 | 指针视差、HDRI 材质照明、曝光 | 使用独立背景，隐藏梦境和 HDRI 图片背景参数；右栏花瓣结构、脱落、材质、独立背景 |

| 7 蝶翼 | 梦境与迎光、指针视差、HDRI、曝光 | 隐藏标本专用的遮挡和层级保护，保留有效太阳与色带；右栏扇翅和翅面材质 |
| 8 斑驳光影 | 场景选择 | 独立二维光影，不提供三维视差、HDRI 和曝光；同名流速、跟随缓动移到左栏 |

- 同名本地参数只是移动控件位置，不合并不同场景的状态；例如纸飞机与蝴蝶各自的 HDRI 质感强度仍可独立保存。真正共享的梦境参数继续由场景2/3/7共同引用。
- 场景不支持的控件隐藏；因播放、云层、路径、光带、Bloom、指针互动开关暂时不生效的控件保留数值、禁用交互并说明条件。原有硬件/加载条件禁用规则保留。
- 修复全局 HDRI 环境强度只影响标本显式 envMap 的问题：普通物理材质通过 `Scene.environmentIntensity` 接收全局强度，标本仍按原有两槽乘法更新，避免重复计算。

## 实现与文件

- `src/viewer/parameterWorkspace.js`、`parameterWorkspace.css`：左右工具栏、共享能力表、同名控件搬移、场景切换刷新、依赖状态、键盘和折叠行为。原控件对象、范围、回调与所有权保留，不改第三方压缩库。
- `src/viewer/parameterHistory.js`：启动调校结束后捕获不可变默认值；参数事务历史最多100步；连续输入/拖动合并；预设及批量默认恢复作为一步；Ctrl+Z、Ctrl+Shift+Z、Ctrl+Y，兼容 Meta。回放调用真实参数回调，同步材质、着色器和动画配置。
- 自动推进的时间不作为普通滑块修改的副作用入栈，显式时间预览和同步重置操作则保留。配色描述选择器与实际颜色区分，回放不会把自定义颜色覆盖成预设。
- 数字输入保持焦点时，先提交文本再回放，最后还原焦点，解决原生 lil-gui 在焦点内不刷新显示的问题。根 finish 事件补齐原库预绑定的滚轮结束路径。
- 左栏“恢复左栏默认”只处理当前提供的公共/同名控件；右栏“恢复本场景默认”包含当前场景已移到左栏的同名控件，不重置其他场景。恢复操作本身可撤销。
- 贴图文件通过 HDRI 单独管理，不进入参数历史；面板已有明确说明。标本旧默认按钮不再重新加载内置文件，避免重置参数时隐式替换用户图片。
- 左右栏可以独立收起，也可以一键收起/展开全部。窄屏打开一栏时关闭另一栏，避免两栏重叠。隐藏栏 inert，不遮挡画布操作；隐藏后保留可键盘访问的展开按钮。
- `createSpecimenViewer.js` 接入与释放工作区；`sceneSwitcher.js` 添加可取消订阅的切换通知。
- `openingScene.js`、`sketchbookScene.jsx`、`featherScene.js` 移除场景私自折叠整套 GUI 的逻辑，折叠状态交由统一工作区。
- `dreamAtmosphere.js` 标注配色方案是派生控件；`environmentManager.js` 修复共享照明强度；`depthPresentation.js` 默认操作保留当前环境文件。

- `npm run build` 通过；保留已有主包大于500 kB的体积提示。
- `npm test`：84项通过；新增6项历史单测，覆盖连续编辑、回调输出、配色事务、默认快照和范围、跨场景稀疏历史、时间预览/播放、旧重置按钮与清理。环境单测补充普通物理场景的全局照明强度。

- `tests/browserHarness.mjs` 按控件原始路径元数据查找搬移后的原生控件，仍通过实际 DOM 输入验证，不依赖生产调试全局。

## 结果与边界

- 用户指定的左右参数布局、无效跨场景控件整理、参数默认恢复/撤销重做、面板收起/展开均实现并验证。
- 参数历史为本次页面会话内的编辑历史，不持久化、不回滚已加载图片文件，不记录单纯的场景切换或手动轨道相机操作。动画阶段参数需进入对应阶段观察，面板有相应说明。
- 具体工具栏样式、同名参数保持场景独立、100步历史为本次实现选择，不写入已确认架构决策。
- 未触碰工作区原有 Blender 删除项、未跟踪模型与参考视频；按工程约定单独提交本任务并推送当前分支。

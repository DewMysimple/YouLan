# 2026-09-05｜按参考重做玫瑰蝶并修复翅膀衔接

- 目标：用户指定按参考图的奶白、玫瑰红斑纹与轮廓重做场景6蝴蝶，缩细并精细化身体，修正扇翅穿模、增加上翻幅度，保留飞行节奏。
- 用户过程中进一步明确：前后翅之间不能出现横向镂空，应像参考图一样连续衔接。
- 日志索引：[[日志/MOC_工作日志|工作日志 MOC]]。
- 约束：[[当前状态/当前约束]]、[[决策/ADR-010-双场景隔离与共享背景]]。

## 实现与取舍

- 在原可复现 Blender 脚本内重建奶白玫瑰蝶。前翅长而上挑、后翅圆润；用原创程序色素场生成玫瑰色不规则碎斑、浅色鳞粉空隙、弯曲主翅脉与分叉细脉，未裁切或投影用户图片。
- 前后翅各使用1536平方的色彩与法线纹理，四张纹理打包进 Blender 和 GLB。网页保留纹理，以低虹彩、非金属、柔和绢面材质呈现，调整场景6自身灯光以保留白色表面层次。
- 胸部半宽由0.17减为0.088，头部由0.19减为0.093；腹部改为连续平滑曲面上的浅分节，避免串珠形状。胸头增加一个合并网格的2200根细绒毛，触角与足缩细，触角及眼睛改为玫瑰色。
- 修正同侧前后翅相位差造成的穿插：同侧前后翅使用相同翅根位置及同步旋转；左右镜像。前翅覆盖后翅，几何的局部厚度方向保留0.016以上的层间净距，间距随翅根一起旋转，避免临近合拢时固定世界间距失效。
- 初次修复曾将前后翅轮廓分开，用户指出横向镂空后改为叠覆轮廓；当前无该空隙。身体与翅根由小型肩部连接体衔接，中央身体与翼面保持间距，连接体允许正常嵌接。
- 循环仍为0.8秒，上翻82度、下压43度，默认动画权重1；保留速度、幅度、悬停起伏、暂停和平展观察控件。
- 原模型文件路径保留兼容性：`source/Blue_Morpho_Butterfly.blend` 与 `public/models/blue-morpho-butterfly.glb` 现在内容为新版奶白玫瑰蝶；场景状态文案同步。
- 仍为风格化薄翼模型，纹样为根据参考方向重新设计，非逐像素复刻；具体美术实现与数值不作为用户已确认的长期规范。

- `scripts/build_butterfly.py`：几何、程序纹理、绒毛、连续腹部与动画。

## 验证

- `npm test`：60/60通过。
- 真实 GLB 验证：四翅UV、四张内嵌贴图、单个0.8秒循环、首尾一致、左右镜像、同侧同步、上翻82度与下压43度。
- 几何验证：5档动画权重，每档121个周期采样；四片翅膀始终保持互不相交的旋转深度区间，翼面不进入中央身体（含绒毛）包围范围。平展时对两侧翅膀衔接处连续射线采样，验证没有横向空洞。
- `npm run build`：通过，既有主包体积提示仍在。
- 浏览器：四片翅膀的1536色彩与法线图均实际解码；暂停按需、速度0、加载失败重试、相机切换恢复、隐藏暂停、减少动画偏好、重复切换资源稳定及直达入口通过，错误为空。
- 人工检查平展、侧面、精确上翻和下压姿态截图，证据在本地 `artifacts/butterfly-rose/final/`。
- 场景默认25次绘制、87082个三角形，仍为单Canvas、独立Scene、共享HDRI。
- GLB约12.84MB，可编辑源文件约12.25MB；较旧版增加主要来自嵌入的纹理，几何绘制量低于旧版。

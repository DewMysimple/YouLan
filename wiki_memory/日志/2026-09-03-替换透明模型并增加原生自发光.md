# 2026-09-03｜替换透明模型并增加原生自发光

- 目标：替换为用户指定的 `source/Specimen_Frame_Transparent.blend`，根据 Three.js 官方资料添加自发光控制。
- 用户确认：采用新模型颜色；仅原生自发光，不添加 Bloom；两槽分别控制，默认强度 0。
- 状态：实现、开发浏览器回归和生产构建验证完成。
- 日志索引：[[日志/MOC_工作日志|工作日志 MOC]]。

## 依据与模型检查

- [MeshPhysicalMaterial 官方文档](https://threejs.org/docs/pages/MeshPhysicalMaterial.html) 明确继承 MeshStandardMaterial；[emissive / emissiveIntensity 官方文档](https://threejs.org/docs/pages/MeshStandardMaterial.html#emissive) 提供原生颜色与强度属性。已同时核对本地 r186dev 的继承关系和属性存在。
- [UnrealBloomPass](https://threejs.org/docs/pages/UnrealBloomPass.html) 是独立后处理，本次用户不选择光晕，因此不引入。
- 新文件只有一个网格 `SPECIMEN_OUTER_FRAME` 和一个相机；两个材质槽仍为外框、内框，无修改器。网格 16 个源顶点、18 个面、36 个三角形，外框/内框各 24/12 个三角形。
- 外框底色维持 `#f3faff`，内框从旧版 `#d1bfff` 改为用户确认的新源色 `#d1aaff`。内框现在包含实体侧面；不擅自简化回旧几何。

## 实现范围

- `scripts/export_specimen.py` 读取新源对象，校验槽位，在导出内存中规范为运行时对象名，导出新的 `public/models/specimen-frame.glb`。源 Blender 文件哈希前后相同，没有写回；不导出相机。
- 运行时继续使用现有 GLTF 适配器，一个 Mesh、两个 groups，索引数 72/36，位置、法线和 UV 均保留。
- `src/viewer/createSpecimenViewer.js` 在两个材质参数组内各添加“自发光颜色”和“自发光强度”：默认白色/0、范围 0–10、步长 0.01，直接操作原生属性并调用按需重绘。
- 不增加自发光贴图、后处理、额外灯光或自定义发光 shader；不修改切片累积模块和本地 Three.js 核心。不改变透射率、粗糙度、IOR、厚度等原有默认值。
- 使用 `make-interfaces-feel-better` 保持既有 lil-gui 控件、中文命名、数字样式和滚动行为；无 CSS 改动、无新增动画或依赖。
- 新增 `tests/specimenAsset.test.js` 和 `tests/browser-emissive.mjs`；更新已有浏览器回归的几何/底色断言，切片测试恢复实际加载的底色。

## 验证结果

- `npm test`：15 项通过，包括 GLB 属性校验及实际 GLTFLoader + 合并适配器测试。
- 新 GLB 一个网格、两个 primitive，不含相机；加载后 56 个分裂法线顶点、108 个索引，位置/法线/UV 数量一致，底色正确。
- 独立 Chrome 操作实际 lil-gui：两槽颜色和强度独立；强度 0、1、10、再次归零均正常，底色和其他物理参数不变。
- 白底内框中心 RGB 从强度 0 的 `(193,142,226)` 到 1 的 `(242,238,247)`，10 时达到白色，归零精确恢复基线；外框及背景采样保持不变。内框以自身紫色发光、强度 0.35 时为 `(222,188,240)`。
- HDRI 加载、隐藏背景、环境强度为 0、各槽环境强度修改和清除均不覆盖自发光参数。正面、侧面、背面与手机滚动截图已检查。
- 100 份新模型保持 10800 索引、两个分组及单 Mesh；发光开关与累积开关互不覆盖。原切片回归验证实际计数 100 而非前后面 200，反面和零间距计数正确，颜色逐级加深。
- 原 HDR/EXR/PNG/JPG/UltraHDR、失败与竞争、2×3 阵列、8 层/256 份上限、重排/禁用/删除/重置、资源稳定、相机、手机面板和重复卸载回归通过。
- 自发光连续切换不增加已稳定的 GPU 资源/程序数，静止不增加渲染帧；刷新恢复无阵列、纯白环境、自发光白色/0。
- `npm run build` 通过，仅保留既有主包大于 500 kB 提示。独立生产预览也通过完整自发光交互测试，采样与开发环境一致。
- 截图和报告保存在独立临时目录，不写入应用默认值；用户的开发服务器保持运行。

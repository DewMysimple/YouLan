# 2026-09-05｜建模蝴蝶并新增扇翅动画场景

- 目标：用户指定建模一只蝴蝶，并在下一个场景展示翅膀扇动动画。
- 日志索引：[[日志/MOC_工作日志|工作日志 MOC]]。
- 既有约束：[[决策/ADR-010-双场景隔离与共享背景]]、[[当前状态/当前约束]]。

## 本轮实现

- 新增场景6“蝶翼”，沿用独立 Scene、共享 Canvas / Renderer / 相机 / OrbitControls / HDRI、中文原生 lil-gui。默认首页仍为场景1；直接预览入口为 `/?scene=butterfly`。
- 从空 Blender 文件建模原创风格化蓝色蝴蝶：弧面前后翅、四个独立翅根、分节腹部、胸部、头部、双眼、弯曲触角及六条腿。翅面使用顶点颜色生成蓝紫渐变、深色翅脉和浅色边缘斑点，无外部贴图依赖。
- 保留可编辑 Blender 文件及可复现生成脚本，导出含 `Wingbeat` 动画的 GLB。四个翅根围绕身体纵轴运动，左右镜像，后翅有少量相位滞后；0.8秒一循环，25个采样关键帧，首尾四元数一致。源文件保存第0帧，避免 NLA 导出前多出一帧停顿。
- 网页通过 Three.js AnimationMixer 播放 GLB 自带动画，AnimationAction 控制速度和幅度；整体轻微悬停、升沉与侧倾独立于翅根动画。展开观察按钮暂停并恢复平展姿态，鼠标可自由旋转查看。
- 翅面使用双面 MeshPhysicalMaterial，保留原顶点颜色并增加可调虹彩；共享 HDRI 配合场景自身柔和主光、轮廓光。背景为独立深青色柔光与一个批次的160个纵深微尘/散景点。
- 首次进入懒加载；失败显示中文状态与重试按钮。切出、页面隐藏、暂停或速度为0时停止动画时间；减少动态偏好默认暂停。卸载时清理动画混合器和专属几何、材质，不释放共享环境。
- 蓝色配色、形态比例、微光背景和运动参数为本轮实现选择，尚未作为用户确认的长期美术规范。模型为风格化建模，并非特定生物物种的科学复原；翼面为弧面薄壳和双面着色。

## 文件范围

- `scripts/build_butterfly.py`：建模、顶点色纹样、翅根动画、源文件与 GLB 导出。
- `source/Blue_Morpho_Butterfly.blend`：可编辑原始模型及 NLA 动画。
- `public/models/blue-morpho-butterfly.glb`：约2.26MB，包含模型与一个循环动画。
- `src/viewer/butterflyScene.js`：模型加载、材质、背景、动画时钟、控件、资源生命周期。
- `src/viewer/createSpecimenViewer.js`、`sceneSwitcher.js`、`panelOrganization.js`：第六场景接入、相机状态、直达链接与面板顺序。
- `tests/butterfly.test.js`、`tests/browser-butterfly.mjs`：真实导出资产和浏览器行为验证。
- 未纳入已有标本源文件删除、用户飞机/地球/花模型、视频或本地 artifacts。

## 资料依据

- [Three.js AnimationMixer](https://threejs.org/docs/pages/AnimationMixer.html)：GLB 动画播放、更新时间、停止及释放。
- [Three.js AnimationAction](https://threejs.org/docs/pages/AnimationAction.html)：循环、速度和权重。

## 验证与结果

- `npm test`：59/59通过。新增验证四个翅根、内置顶点色、左右镜像、后翅滞后、明显扇动幅度、首尾姿态、身体稳定、资源释放及共享环境保留。
- `npm run build`：通过；仍有既有主包大小提示。
- `tests/browser-butterfly.mjs`：模型加载失败后重试、实时扇动、暂停按需渲染、平展观察、速度0、真实鼠标旋转、相机切换恢复、非活动时间冻结、反复切换资源稳定、页面隐藏、减少动态偏好与直达链接均通过，浏览器错误为空。
- 实际场景默认30次绘制、104534个三角形、单Canvas；包含四片翅膀与身体细节。截图、浏览器报告位于本地 `artifacts/butterfly/verified/`，不提交截图。
- `tests/browser-paper-orbit.mjs` 回归通过，场景5默认仍2400架飞机、7次绘制，暂停、资源切换及减少动态偏好通过，错误为空。
- 视觉检查包含展开、扇动及侧面观察截图。

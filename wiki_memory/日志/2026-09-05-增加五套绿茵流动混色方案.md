# 2026-09-05｜增加五套绿茵流动混色方案

- 目标：用户指定把原粉黄紫三色作为一个配色方案，并参考林间绿光、水光图片新增绿茵方案；随后要求多套绿茵可选。
- 日志索引：[[日志/MOC_工作日志|工作日志 MOC]]。

## 实现与文件

- `src/viewer/dreamAtmosphere.js`：在“梦境背景与迎光 → 流动混色个性化”顶部添加“配色方案”。
- 保留原粉彩默认 `#ffb9e7 / #fff19b / #b787f5`，新增五套绿茵。
- 林间晴光：`#83bf65 / #fff6b0 / #65b7a2`；晨露薄荷：`#a2ce83 / #f5f5ce / #72b8a2`；青溪水光：`#6dbb82 / #d8edab / #429c9a`；午后草甸：`#76ad45 / #f4e88b / #4c9865`；幽林萤光：`#376947 / #dce99b / #286b64`。
- 方案仅修改三色，保留当前混色图案、动画、亮度与太阳控制；继续共享给标本、花粉和蝶翼。
- 手动改色自动识别为“自定义”；重新匹配预设时恢复方案名。局部和整体恢复均同步名称、颜色控件。
- 选择器状态位于面板层，不加入着色器输入；沿用按需渲染和刷新恢复默认约定。
- 参考图仅用于配色方向，不添加图片贴图。具体方案名称与色值是本次美术实现，未作为永久规范确认。

## 验证

- 生产构建通过；保留既有主包体积提示。
- 原流动混色浏览器回归通过：颜色/图案像素变化、灰度遮罩、三场景共享、遮挡隔离、恢复、暂停回到按需渲染与资源数量稳定；零浏览器错误。
- 临时浏览器验证检查全部五套颜色控件与 shader 三色一致、三场景共享、保留图案、自定义状态、局部/整体恢复和非混色模式禁用，全部通过。
- 人工查看浅薄荷、晴光和深绿截图；验证脚本与截图位于 `artifacts/green-palette/`，不纳入源码提交。

## 结果与遗留

- 完成一套原粉彩与五套绿茵方案，可切换后继续独立微调。
- 无遗留问题；保留无关源文件删除与未跟踪用户资源。

# 2026-09-05｜将Character接入场景11

- 时间：2026-09-05（北京时间）
- 状态：完成
- 目标：将用户指定的桌面 Character 工程接入幽兰，编号必须是场景11。
- 日志索引：[[日志/MOC_工作日志|工作日志 MOC]]

## 已确认的需求

- 用户明确指定接入桌面 Character 工程，且强调使用“场景11”。
- 保留现有场景编号，选择器新增“场景11·字符物理实验”。

## 检查与实现

- Character 是 Canvas 2D 字符物理与花园动画工程：代码卡片局部坍塌、字符薄片气动翻滚、化蝶、花朵生长与生态访花。
- 原样复制四个引擎文件到 `src/viewer/character/`，逐字节验证一致；不修改原 Character 工程，不复制其视频、依赖、构建目录或独立 React 界面。
- 用独立 Scene 和 CanvasTexture 接入现有 WebGL Canvas；原720×960设计画面等比居中，周边延伸纸色背景，使用原始颜色，不套用三维曝光或梦境效果。
- 进入场景11才初始化引擎。主渲染循环驱动引擎，不增加第二套 requestAnimationFrame；切换离开和后台暂停，保留演出进度，返回继续。
- 保留37个数值参数与原始范围、四种坍塌模式、指针开关，分为文字坍塌、坠落物理、字符渲染、蝴蝶飞行、指针扰动。
- 提供播放/暂停、0–8秒时间预览、重播、恢复参数、进度/蝴蝶/花朵状态；恢复参数保留当前时刻。8秒后蝴蝶继续飞行。
- 指针按实际等比画面坐标映射；快捷键仅在场景11生效，输入框编辑时不抢占键盘。二维场景停用 OrbitControls 与指针相机视差，切回三维恢复。
- 直达地址支持 `?scene=11` 和 `?scene=character`。

## 文件范围

- `src/viewer/character/`：四个原始TS引擎文件、从原控制面板提取的参数表与来源说明。
- `src/viewer/characterScene.js`：场景适配、纹理、交互、面板和清理。
- `src/viewer/createSpecimenViewer.js`：渲染、切换接线、窗口、后台与销毁。
- `src/viewer/sceneSwitcher.js`：明确编号11、面板显隐、二维控制恢复。
- `src/viewer/panelOrganization.js`、`src/styles.css`：面板顺序及状态文字样式。
- `tests/browser-character.mjs`：浏览器完整演出和集成验证。

## 测试与验证

- `npm test`：70项通过。

- 开发服务器浏览器验证通过：场景11编号、懒初始化、唯一DOM Canvas、0/2/4.5/8秒演出、完成态继续飞行、指针事件、四种坍塌模式、100/220字符、恢复默认、切换状态与相机恢复、资源稳定、DPR2窗口适配、减少动态和直达链接。

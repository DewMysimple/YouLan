# 2026-09-03｜添加外壳与内胆柔和轮廓

- 目标：用户提供三张侧面、顶部转角标注，要求外体和内体的四角有轻微可见的边，改善侧面缺失感，不能成为显眼线框。
- 范围：仅材质渲染与现有中文面板，不改源模型、运行时 GLB、两槽原色、阵列几何、内胆补色或切片累积公式。
- 索引：[[日志/MOC_工作日志|工作日志 MOC]]；约束：[[当前状态/当前约束|当前约束]]。

## 依据与实现

- 官方 [Material.onBeforeCompile](https://threejs.org/docs/pages/Material.html#onBeforeCompile) 支持在 WebGLRenderer 中扩展原生材质；配合 `customProgramCacheKey` 保留已有编译缓存。查阅 [EdgesGeometry](https://threejs.org/docs/pages/EdgesGeometry.html) 后，未采用额外线网格：当前内胆侧壁来自闭合投影，单纯提取 GLB 边不能对应其完整显示边界。
- 新增 `src/viewer/softEdges.js`，在原生物理着色之后、颜色输出之前做轻微中性明暗处理；不是 Three.js 自带倒角参数，也不是真实几何倒角。所有可见面按两个箱体边界形成细边，包含四角连接正反面的厚度方向短边，不显示三角面剖分线。
- 外壳从不可变单件包围盒取得边界；内胆共享 `embeddedCore.js` 的同一相交函数和实时状态，沿实际闭合投影的入射面画边，避免另一个箱体轮廓错位。阵列保留每份 `corePosition`，不扩大单件包围盒或增加 Mesh、绘制遍次、纹理。
- 使用局部位置导数生成柔和抗锯齿，宽度随设备像素比例调整；不把边线放入自发光代理或 Bloom，不在背面透射预遍次重复叠加暗色。外壳透射为零时不显示投影内胆边，内胆不透明度归零时不保留投影残线。
- 渲染设置新增“轮廓清晰度”0–1（本次默认 0.32）和“轮廓宽度（像素）”0.5–2（默认 1）。清晰度 0 关闭；恢复默认恢复两值，纯透射对照关闭轮廓；环境切换不重置轮廓。参数仅当前页面有效。
- 沿用原生 lil-gui，不改样式体系、布局或增加动画。界面细节技能用于克制的细线与现有控件一致性，不套用其图片描边 CSS 到三维材质。
- 按需更新共享状态，卸载按相反顺序还原材质扩展钩子；保留双槽独立参数。

## 验证

- `npm test`：26 项通过。新增材质扩展串联、单一投影定义、背面保护、导数抗锯齿、数组坐标、数值防护、零强度与清理测试。
- `browser-edges.mjs` 开发和生产通过：正面、纯侧面、近侧上方、斜角、背面及底部；16/100 份；HDRI、隐藏背景、纯白；两槽透射归零再恢复、不透明度归零、默认恢复、对照关闭、重复调参、空闲及移动端。
- 10 组开关像素对照均能检测到细边。单件与独立 CPU 投影的 24 条箱体边比对，变化像素全部位于约 2.01 像素范围内，三像素范围外变化为零；不是整面加深。测试初版错误假设斜视的屏幕中心必在面内，后改用真实投影边界判定，避免把中央转角当误着色。
- 正面与纯侧面的中心像素保持不变；各场景视口平均差小于 0.41/255。100 份仍为一个 Mesh、两个分组，两槽色值 `f3faff`、`d1aaff`。重复调参 GPU 计数稳定为 16 几何、24 纹理；静止不持续渲染。
- 手机 390×844、DPR 2 输出为 780×1688；两个新控件能滚动到视口内并调节。人工查看开关对照、阵列、纯白和移动端截图，确认顶部、侧面及内胆转角连接。
- `browser-core-closure.mjs` 通过：13 视角仍无颜色越界、缺口或重复计数；中性环境六向中心均为 `(189,126,227)`，正侧面 1/2/5/16/100 层仍使用同一加深序列。
- `browser-depth.mjs` 通过：默认正面、原始色值、颜色累积、局部 Bloom、刷新、资源与空闲；原默认中心仍为 `(203,118,245)`。
- `browser-regression.mjs` 通过：HDR/EXR/PNG/JPG/UltraHDR、竞争与错误保留、双槽独立、2×3、8 层/256 份、数组修改与重置、按帧合并、面板滚动及两次显式销毁。
- `browser-emissive.mjs` 通过：原生发光 0/1/10/归零、双槽独立、白底/HDRI/隐藏背景、100 份与刷新。首次运行缺少测试输出目录，创建目录后完整重跑通过，未修改运行时代码。
- `npm run build` 通过，45 模块，只保留原有大于 500 kB 的主包提示。
- 源 Blender 和 GLB 的 SHA-256 在本轮前后相同；记忆索引刷新，记忆检查 35 页通过，差异空白检查通过。
- 生产截图和检测报告保留在本次临时验证目录 `yulan-edges-production`；测试截图不成为运行时依赖。

## 交付与边界

- 涉及 `src/viewer/softEdges.js`、`embeddedCore.js`、`createSpecimenViewer.js`、`depthPresentation.js`，新增 `tests/softEdges.test.js`、`browser-edges.mjs`；工程记忆同步后按约定提交推送。
- 当前算法适用于矩形外壳、矩形内胆和只平移的阵列。不是物理倒角、内部多次折射、隐藏线透视或真实嵌套介质追踪；高曝光/强发光可能让细边变淡。
- 源 Blender、GLB、本地 Transmission 核心及 Blender 仓库未修改；不把三个旧 Blender 文件的既有用户删除纳入提交。

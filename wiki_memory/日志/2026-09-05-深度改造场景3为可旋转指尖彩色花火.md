# 2026-09-05｜深度改造场景3为可旋转指尖彩色花火

- 目标：用户认为原场景3过于单薄，要求结合提供的视频与指尖烟花网站深度改造；随后明确要求保留 Three.js 旋转。
- 索引：[[日志/MOC_工作日志|工作日志 MOC]]。
- 前置：[[决策/ADR-011-隔离烟花场景与GPU批量轨迹]]、[[日志/2026-09-04-分析参考视频并实现隔离金菊闪柳场景]]。

## 参考分析

- 读取用户桌面主工程 source 中的“周末花100块Vibe-coding一个赛博烟花手指触摸或鼠标点击即可观看一场带声音的烟花盛宴，发给你想让他看烟花的人吧.mp4”：29.13秒、720×1128，包含音轨；按3秒间隔抽帧对照用户旧效果截图。
- [指尖烟花网站](https://finger-fireworks.aganztracywork.workers.dev/) 当日呈现蓝色纸幕、彩色粗细笔触、卷曲弧线、枝端二次绽放、多朵叠放和声音。检查当日公开页面及 painted-fireworks--AzYY3Fh.js，确认原站以二维绘制笔触为主；不照搬网站界面、字体或音频资产。
- 原场景3单朵中央循环、细金线与微弱绿闪，缺少参考中的色彩与体量。改为彩色指尖花火默认模式，同时保留原版金菊闪柳完整参数作为对照。

## 用户确认与实现选择

- 用户直接要求支持 Three.js 旋转：最终使用真正世界空间花火轨迹与透视投影，不是只能正面观看的屏幕平面。保留 OrbitControls 旋转、缩放、平移和场景相机状态。
- 单击发射，拖动旋转，滚轮缩放；拖动位移超过6像素不触发发射，多指操作不误发射。旋转后使用射线与当前视平面求交放置爆点。取消开发过程中的拖动连发方案，避免手势冲突。
- 使用 make-interfaces-feel-better 技能指导交互状态、原生面板一致性、减少动画偏好与按需绘制；烟花本身作为用户要求的主要动态内容保留。
- 彩色色带按渐细、纺锤、颗粒和淡入淡出生成，使用一个预分配 InstancedBufferGeometry：10朵上限，每朵64主枝、48二次枝与1火箭，共1130条实例；另用固定320点批次绘制短暂爆心和碎星。二次花继承真实主枝的角度、深度与种子。每帧仅更新时间，发射和调参才改写实例属性。
- 世界空间轨迹沿Z分布；色带宽度在视平面展开，使绕看时不会变成不可见薄边。蓝色纸幕保持背景，不跟随旋转；右侧仍只用已有原生中文 lil-gui。
- 默认自动错落连发、可手动五彩齐放；提供三套烟花配色、三套天空预设、大小/数量/卷曲/纵深/厚度/颗粒/柔光与画质调节。满额时保留正在绽放的烟花，不突兀覆盖。
- 音效为原创程序噪声合成的升空啸声和低频爆声，带左右声像、主音量和压缩限幅；首次用户点击才创建并解锁 AudioContext。不下载背景音乐或原站音频。暂停、隐藏、切换、静音与销毁时停止声音。
- 新旧模式使用各自时间线、背景、配色、Bloom参数；后处理按活动模式读取参数。未修改旧烟花模块算法、其他场景资产、桌面主线或源视频。

## 验证

- 构建通过，保留原有主包体积超过500KB的提示；无新增依赖、锁文件改动或远端运行时素材。
- 68项单元测试通过，包括固定批次、确定性时间预览、二次花真实父枝、隐藏/暂停/减少动态、容量边界、世界坐标、清理及声音锁定/限额/静音。
- 新场景浏览器检查通过：着色器编译、单Canvas、暂停按需绘制、点击落点、真实AudioContext用户点击后解锁与声源触发、静音状态、三维拖转/缩放、拖动不发射、旋转后射线落点、10%速度检查、减少动画、竖屏DPR2触屏点击、场景1–7往返和新旧模式预热后资源稳定；无浏览器控制台错误。
- 原版烟花浏览器回归通过：分阶段画面、独立夜空、时间线、按需渲染、质量/数量、相机恢复、资源稳定和面板滚动。
- 场景7浏览器完整回归通过，仍为二维光影、禁用旋转，与新场景3的三维交互隔离。
- 工作分支沿用 `codex/scene7-dappled-light`；fetch确认当前上游分支没有新提交。远端main另有蝶翼更新，不将其混入本烟花交付；桌面主工程未写入。

## 结果与边界

- 默认场景3升级为“指尖花火”，效果参考视频但为适配可旋转三维空间的重新实现，不声称逐像素复制。最多10朵同时存在。
- 视觉与音效主观偏好仍待用户体验确认；音效触发与生命周期已验证，不声称原视频音轨复刻。竖屏做交互冒烟检查，不扩展为移动设备性能保证。
- 美术默认数值、10朵容量、两模式并存属于本轮实现选择，未将其提升为用户确认的永久架构规范。

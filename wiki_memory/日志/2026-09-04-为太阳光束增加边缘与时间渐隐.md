# 为太阳光束增加边缘与时间渐隐

## 目标

延续“太阳离开相机视口后才隐藏光束”的规则，消除视口边界上的 0/1 跳变。太阳移出时光束须逐渐衰减，移回时须逐渐增强，并允许在参数面板调节过渡。

## 机制

- `src/viewer/dreamAtmosphere.js` 将太阳投影门限改为连续值：以太阳圆盘到最近视口边缘的有符号屏幕距离为输入，使用 `smootherstep` 生成 0–1 空间渐隐。横向距离按相机宽高比换算，避免宽屏上的渐隐带被拉伸。
- 新增“边缘渐隐范围（%）”，默认 6%，范围 0–25%；控制圆盘跨越画面边缘时的空间软带。
- 新增“显隐过渡时长（秒）”，默认 0.45 秒，范围 0–2 秒；使用帧率无关阻尼追随空间目标值，中途反向不会跳变，0 秒可恢复即时响应。
- 过渡达到 0 或 1 后精确吸附并停止额外帧，保留静止时按需渲染。页面隐藏时暂停时钟，恢复时不计入后台经过时间。
- 只对相机视口的进入/离开使用渐变。关闭梦境效果或将亮心强度设为 0 属于明确参数命令，仍立即关闭，避免背景光纹残留。
- 同步 `panelOrganization.js` 的迎光分组和中文面板说明；模型、双槽材质、纵深几何与色值未改。

## 验证

- `npm test`：34/34 通过；覆盖空间中间值、精确端点、双向阻尼、中途反向、停止额外帧及显式关闭立即生效。
- `browser-infinite-depth.mjs`：75° 画内 gate=1；快速移出约 0.2 秒 gate≈0.264，随后为 0；快速移回约 0.2 秒 gate≈0.746，随后为 1；边缘软带 gate≈0.286。
- 同一浏览器回归确认 200 层、间距 10 不改变显隐规则，72 个面板控件可用，资源与浏览器错误检查通过。
- `browser-dream.mjs`：动态背景、遮挡、线性输出、纵深、资源、降低动态偏好与页面可见性完整回归通过。
- `npm run build`：通过，仅有既有主包体积提示。

## 结果

太阳光束不再在视口边界瞬间跳变。空间软带负责慢速拖动时的自然渐隐，时间阻尼负责快速甩动时仍保留可见过渡；两者可独立调节。关联决策：[[决策/ADR-008-统一纵深控制与无限远亮心|ADR-008]]。

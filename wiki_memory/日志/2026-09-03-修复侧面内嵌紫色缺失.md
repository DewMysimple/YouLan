# 2026-09-03｜修复侧面内嵌紫色缺失

- 目标：用户指出标本框侧面中间像镂空，没有内嵌紫色；要求解决实际显示问题。
- 保留源 Blender、当前闭合 GLB、两槽原色、独立材质、局部自发光、HDRI、阵列及按需渲染。
- 日志索引：[[日志/MOC_工作日志|工作日志 MOC]]；相关呈现范围见 [[决策/ADR-006-深邃默认呈现与局部光晕|ADR-006]]。

## 根因与资料

- 当前 GLB 的外壳是闭合的，并非丢失外侧几何；但内框颜色只位于正反面。正侧视时，两个紫色面的投影趋于零宽，外侧面的原生透射不等同于光线穿过一个有内部颜色的实体。
- 上一轮删除内部侧壁只解决三面共边与外壳闭合，未解决紫色内部介质的显示语义。用户此次明确要求侧面能看见内嵌紫色；不是要求把所有外框侧面改成紫色材质。
- 查阅 [MeshPhysicalMaterial 文档](https://threejs.org/docs/pages/MeshPhysicalMaterial.html)、[透明度手册](https://threejs.org/manual/en/transparency.html)、[r185 WebGLRenderer 源码](https://github.com/mrdoob/three.js/blob/r185/src/renderers/WebGLRenderer.js) 及 [原生透射着色器](https://github.com/mrdoob/three.js/blob/r185/src/renderers/shaders/ShaderChunk/transmission_pars_fragment.glsl.js)。原生厚度、透射、衰减描述材质边界和采样；不自动把两种面颜色解释为嵌套色体。额外逻辑属于项目自定义近似，不宣传成官方提供的递归折射功能。

## 实现

- 新增 `src/viewer/embeddedCore.js`：从不可变基础几何的内框分组推导长方体范围，表达内嵌色体；不补回相交内部壁，不改 GLB 或 Blender。
- 在外框材质前表面透射结果中，仅对几何侧面沿首界面折射方向做局部射线/包围盒相交。未穿过内芯的位置不加颜色；不改正反面原有原生颜色及累积公式。
- 根据实际交段长度做有界颜色吸收，直接读取内框的线性底色、不透明度、透射率及可见性。透明度为零不留残影；纯白内框不强行显示紫色；透射率降为零采用局部漫反射照明近似，不把内芯变成空白。
- 第一版长路径吸收过重，视觉检查后改为平滑有界长度，保留紫色厚度感而不过度趋近深蓝。
- `corePosition` 属性保留每个副本内的原始坐标；阵列仍仅平移真正的位置属性，局部色体不会固定在原件世界位置。模型世界逆矩阵逐次按需绘制更新，支持根节点坐标适配。
- 仅外框着色器增加分支；内框材质参数对象不合并，不改变两槽底色、原 UV/UV1、法线、分组、顶点位置或索引。没有新增 Mesh、纹理、离屏目标或额外渲染遍次。
- 渲染设置增加默认开启的“内嵌色体透射”；恢复默认会开启，“纯透射对照”关闭该近似，“仅颜色层级对照”保留内芯。卸载按逆序恢复扩展钩子，几何仍由原阵列/模型生命周期释放。
- 沿用中文 lil-gui 和 CSS；根据 make-interfaces-feel-better 的文字排版与轻量反馈要求复用既有说明样式，不新增动画、字体或界面框架。

## 适用范围与边界

- 这是当前长方体标本框侧向内嵌色体的渲染修正，不是新增可导出的内部几何，也不是完整的嵌套介质路径追踪。
- 色体根据当前内框包围盒表达，依赖当前矩形内芯、局部 X 厚度、仅平移阵列契约；未来非矩形内芯、旋转缩放修改器或新模型须重新审查。
- 不模拟内芯逐层发光传输、多个副本之间的完整折射及内部光照。纯透射对照关闭修正以避免混淆原生能力。
- 保留三个旧 Blender 文件的用户删除，不混入本次提交。局部测试浏览器与预览进程由本任务启动并在结束后清理，用户开发服务器继续运行。

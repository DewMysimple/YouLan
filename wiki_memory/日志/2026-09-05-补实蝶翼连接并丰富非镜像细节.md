# 2026-09-05｜补实蝶翼连接并丰富非镜像细节

- 目标：用户指出身体连接处仍显镂空、前翅上缘不够饱满、左右细节完全镜像，指定继续按附图调整。
- 关联：[[当前状态/当前约束]]、[[日志/MOC_工作日志]]。

## 实现

- 将仅靠小肩部连接点的翅根改为宽幅近端翅膜，沿胸部纵向嵌接，肩部覆盖体变为细长低矮形状。平展时胸部两侧及上下的空隙明显收拢，保持细身体比例。
- 近端翅膜允许在肩部区域正常嵌接；自由翼面保持中央身体之外。前后翅继续使用随翅根旋转的独立深度层，保持叠覆与同步动画。
- 重画前翅上缘：增加内侧弧线的饱满度、拓宽圆润翼尖、降低轮廓细锯齿幅度。左右外轮廓仅作轻微差异，整体保持平衡。
- 左右前后四片翅膀分别设计主色斑的位置、数量、尺寸和留白，使用各自确定性的鳞粉噪声与细脉弯曲差异。原两套共享纹理改成四套独立色彩/法线纹理，均为1536平方。
- 保留0.8秒循环、上翻82度、下压43度与现有场景控制。
- 文件：`scripts/build_butterfly.py`、`source/Blue_Morpho_Butterfly.blend`、`public/models/blue-morpho-butterfly.glb`、`tests/butterfly.test.js`。
- 保留原模型路径；新版GLB约23.68MB，Blender源文件约23.10MB。体积增加来自不再共用左右纹理，绘制次数与三角形数未增加。

## 验证

- `npm test`：60/60通过；`npm run build`通过，既有主包大小提示仍在。
- 导出资产检查四个独立翼材质、八张内嵌纹理；确认四张色彩图的数据不同，避免仅分配不同引用却保留相同图案。
- 肩部由单条横向射线升级为二维区域采样，覆盖胸部上下的连接范围；保持既有翅膀交界连续性检查。
- 5档动画权重、每档121个周期采样，检查前后翅保持互不相交的旋转深度层，以及远离连接处的自由翼面不进入中央身体包围范围。近端翅膜的正常身体嵌接不误判为自由翼穿模。
- 浏览器套件通过：四翼色彩与法线纹理实际解码、动画、暂停、速度0、失败重试、相机切换、资源稳定、隐藏暂停、减少动画偏好和直达入口均正常，无控制台错误。
- 检查平展、上翻与下压截图，证据位于本地 `artifacts/butterfly-fuller/draft/`。默认25次绘制、87082个三角形。

# 2026-09-05｜接入Codrops纵深花廊场景8

- 目标：用户指定把本机 `codrops-depth-gallery` 加到下一个场景，并做适配性参数调整。
- 索引：[[日志/MOC_工作日志|工作日志 MOC]]；前置：[[决策/ADR-010-双场景隔离与共享背景]]、[[日志/2026-09-05-新增微软参考二维斑驳光影场景7]]。

## 来源与实现

- 阅读原项目 Gallery、Scroll、Background、Trail、Engine、数据和截图，确认五幅花卉图片、深度滚动、相邻图交叉淡化、逐图配色、指针视差及滚动驱动的空间光带。原光带并非鼠标轨迹。
- 原图原样复制到 `public/gallery/depth/`，保留原 MIT LICENSE 与作者/图片来源说明；不修改用户原项目，不复制依赖、外部字体或网站导航。
- 新增 `src/viewer/depthGalleryScene.js` 与 `src/viewer/depthGallery/`：复用本地 Three 核心和唯一 Canvas / Renderer；独立 Scene、相机、背景、参数与生命周期，不进入共享 HDRI 管线。图片首次激活才加载，失败可重试，卸载后的迟到纹理也释放。
- 沿用原背景 GLSL 并修正反向 smoothstep 的未定义边界。光带使用同源正弦空间路径和固定128段缓冲，微粒固定24点，避免原版逐帧重建 TubeGeometry。
- 默认滚动灵敏度0.75、缓动0.22秒、错落0.75、视差0.12、呼吸0.022、氛围速度0.65、颗粒0.028。纵深间距3.5–7时同步调整相机和图片尺寸，保证每幅停靠构图一致。窄屏收拢横向偏移并按可见宽度缩放。
- 原生中文面板提供穿行进度、构图、滚动/指针缓动、氛围动画、光带、恢复和加载重试。仅Canvas接收滚轮和拖动，不抢占GUI滚动；场景8临时关闭OrbitControls，返回三维场景恢复操作。
- 关闭氛围动画后，滚动与指针稳定即停止绘制；减少动态偏好禁用持续氛围、微粒和呼吸，仍支持直接导航。非活动与隐藏页面不推进时钟。
- 接入文件：`src/viewer/createSpecimenViewer.js`、`sceneSwitcher.js`、`panelOrganization.js`、`src/styles.css`。预览支持 `?scene=gallery` / `?scene=8`，默认首页仍为场景1。
- 使用交互细节技能检查可中断缓动、减少动态与原有样式体系，未引入新依赖。

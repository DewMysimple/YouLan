# 当前约束

## 技术约束

- 页面技术栈为 React + Vite + Three.js + WebGL。
- Three.js 核心使用 `source/threejs-transmission/build/three.module.js`；运行时不依赖 CDN。
- GLB 必须保留 `SPECIMEN_OUTER_FRAME` 和 `SPECIMEN_INNER_PANEL` 两个对象名。
- 两个网格分别拥有独立 `MeshPhysicalMaterial`，不得共享材质状态。

## 交互与界面约束

- 页面只显示全屏模型、原生 lil-gui 中文参数面板和加载失败提示，不添加额外装饰界面。
- HDR 同时用作环境反射和可见背景。
- 视角采用 Three.js 默认 Y-up 相机轴系；模型根节点负责适配 Blender 原始正面轴向。
- 默认不自动旋转，鼠标和触控由 OrbitControls 操作。

## 质量约束

- 保持按需渲染；参数变化、相机变化、资源加载和窗口缩放时才重绘。
- React 卸载时必须销毁 GUI、控制器、材质、几何体、纹理和渲染器。
- 完整任务需执行相关构建和交互验证。

## 操作边界

- 保留 Blender 原件、示例源码、视频和远端已有资产。
- 按 [[知识/规范/Git任务提交约定|Git 任务提交约定]] 完成提交和推送。

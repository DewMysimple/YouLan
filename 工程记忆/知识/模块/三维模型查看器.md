# 三维模型查看器

## 一句话结论

`src/viewer/createSpecimenViewer.js` 完整拥有 Three.js 场景生命周期，React 只负责挂载、错误显示和卸载。

## 关键契约

- 运行时模型：`public/models/specimen-frame.glb`。
- 必需对象名：`SPECIMEN_OUTER_FRAME`、`SPECIMEN_INNER_PANEL`。
- 本地环境图：`source/threejs-transmission/examples/textures/equirectangular/royal_esplanade_2k.hdr.jpg`。
- 外框和内板分别创建材质及 GUI 参数对象。
- 模型根节点旋转适配标准 Three.js 相机轴系。

## 常见修改位置

- 材质默认值与中文控件：`DEFAULT_MATERIAL_PARAMETERS`、`bindMaterialFolder()`。
- 初始朝向与自动取景：`frameModel()`。
- 资源释放：`disposeObjectResources()` 与查看器返回的清理函数。

## 常见陷阱

- 不要把相机 up 改为 Z 来迁就模型正面；应旋转模型根节点。
- 不要让两个网格共享同一材质或同一参数对象。
- 修改控件后要调用 `requestRender()`，否则按需渲染不会刷新画面。
